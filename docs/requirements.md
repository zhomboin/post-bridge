# 多平台内容发布系统需求规划

## 1. 文档用途与项目目标

本文件是项目需求入口，描述完整首期范围。当前实现单管理员、单 CSDN 账号的文字 Markdown 草稿后台，包含持久队列、独立执行器、任务与日志、Ubuntu systemd 部署及后台无桌面远程验证；操作见[开发说明](development.md)，证据见[验收记录](acceptance.md)。PostBridge 侧来源注册、签名、平台稿确认及守卫已实现并本地验证；公开发布、图片、MDX、其他平台、CMS 实际连接和生产上线继续按本文实施，不能用草稿验收替代。

系统面向个人内容创作者，将来自 CMS 等来源的文章转换并发布到多个平台。首批目标平台为 CSDN、知乎和小红书，后续按相同接入规范扩展。

已确认的产品要求：

- 系统独立开发、独立部署，CMS 作为内容来源接入。
- 正式运行完全由后台固定程序执行，不依赖 AI Agent、大模型服务或模型密钥；开发阶段可使用 AI 辅助编写和审阅代码。
- 提供独立管理后台，集中查看发布记录、分平台状态、任务详情和相关日志；所有前端实现与审阅遵循项目内两个设计技能。
- 发布文章时可选择目标平台，确认后由服务器自动完成对应平台的发布操作。
- 用户关闭电脑或退出管理页面后，服务器继续执行任务。
- 接受浏览器自动化的适配和维护成本；官方接口在确认权限和能力后优先使用。
- 平台要求扫码、短信或验证码时暂停任务，用户在受保护的后台入口处理后继续。
- CMS 保持自有博客的内容管理和运维职责，第三方账号、内容适配、浏览器及分发调度由本系统承担。

本文标为“首期默认”的内容用于形成可执行范围；标为“建议”的技术选择可在新项目初始化时调整，但必须维持上述产品要求。

## 2. 系统边界

| 能力                                       | 内容来源 CMS   | 本系统                       |
| ------------------------------------------ | -------------- | ---------------------------- |
| 原始文章、草稿、私有内容与修订             | 管理           | 仅接收明确授权分发的内容快照 |
| 自有博客发布、下架、评论、相册、统计和运维 | 管理           | 不接管                       |
| 第三方平台账号、授权、登录与验证           | 不管理         | 管理                         |
| 各平台标题、正文、标签、封面和图片转换     | 不实现平台规则 | 管理                         |
| 任务调度、自动发布、失败恢复及结果核对     | 展示必要摘要   | 管理                         |
| 外站文章链接、更新关联及撤回状态           | 可展示摘要     | 管理                         |

本系统不得直接读取 CMS 数据库、依赖 CMS 内部表结构，或将平台文案修改回写为 CMS 原稿。两个系统不得共用后台登录密钥或第三方账号凭据。

CMS 对接代码由 CMS 项目实施；本项目交付通用接口契约、来源接入说明和联调验收要求。

## 3. 首期范围与范围外事项

首期默认服务一名管理员，接入一个 CMS，每个平台绑定一个账号。来源、账号与任务仍使用独立标识，避免与具体 CMS 或账号名称绑定。

首期必须包含：

- 独立后台登录与受认证保护的管理接口。
- 独立管理后台包含总览、发布记录、任务详情和日志中心，支持筛选、分页、刷新及异常处理。
- 内容来源登记、连接凭据管理和连接状态检查。
- CSDN、知乎、小红书三个目标平台的能力验证及适配。
- 平台账号绑定、登录状态检查、受保护的远程登录及验证处理。
- 接收文章快照、选择平台、平台内容预览和独立调整。
- 立即分发、持久化任务、平台内串行执行、有限重试和重启恢复。
- 自动上传素材、填写内容、提交发布、记录结果及外站链接。
- 分平台进度、登录异常提醒、失败原因、结果核对及继续执行入口。
- 原稿更新、下架和转私有的通知处理，以及外站副本状态说明。
- 部署、备份恢复、日志管理、凭据保护和必要的运行监测。

首期不包含：多人团队与收费、多账号矩阵、定时发布、批量历史文章搬运、互动数据汇总、评论管理、AI 改写、自动生成配图、跨平台自动删文，以及其他平台接入。

三平台全部通过约定验收才可称为首期全部交付。若某平台无法完成真实账号验证，应单独记录阻塞和影响；不得自动改为人工复制、只生成草稿或只打开发布页面后标记完成。

## 4. 页面与使用流程

### 4.1 管理页面

本系统自有管理后台独立于 CMS，首期服务一名管理员。页面结构、日志字段、模板参考和交互要求以[管理后台与界面规范](admin-ui.md)为准；[前端技能说明](frontend-skills.md)记录必须共同使用的设计与审阅技能。

| 页面 | 必要能力 |
| --- | --- |
| 登录 | 管理员认证、退出和会话失效处理 |
| 总览 | 发布任务摘要、待处理事项、账号异常和执行器健康提醒 |
| 发布记录 | 按文章查看父任务与平台结果，按来源、平台、账号、状态及时间筛选 |
| 任务详情 | 原稿与快照、各平台执行和审核状态、外站链接、尝试记录及关联日志 |
| 处理记录 | 按对象的一次处理查看平台、任务、字段前后值、完整状态流转和结果；不同处理各占一条，保留全部日志筛选入口 |
| 平台账号 | 绑定账号、显示身份、检查状态、重新登录和解除绑定 |
| 内容来源 | 登记 CMS、管理连接权限、轮换凭据及检查连接 |
| 分发稿 | 来源快照、平台预览、平台文案编辑和兼容性检查 |
| 验证处理 | 指定账号的受保护临时远程浏览器会话 |
| 系统设置 | 并发、超时、有限重试、记录保留、健康状态和展示时区 |

### 4.2 CMS 发起发布

1. CMS 获取本系统返回的平台、账号可用状态和能力说明。
2. 用户在 CMS 发布确认界面勾选平台；第三方平台默认不勾选，保留仅发布自有博客的选择。
3. CMS 保存原稿，并为用户展示基于同一内容版本生成的平台预览；需要单独修改的平台内容在本系统完成编辑。
4. CMS 确认当前分发内容与用户预览一致后，完成站内发布并可靠提交分发请求。
5. 本系统快速返回任务标识，服务器异步执行，CMS 显示状态摘要和任务详情入口。
6. 用户离开页面或关闭电脑不影响任务执行；任务遇到验证时暂停，处理完成后继续。
7. 每个平台分别展示已提交、审核中、已公开或失败等结果。

平台预览可通过跳转本系统完成，首期无需将完整平台编辑器嵌入 CMS。内容转换与平台校验在本系统集中完成。

### 4.3 平台内容准备规则

- 勾选平台后先进行字段、素材和格式校验，发现问题时在确认分发前提示。
- 预览成功、校验通过且原稿版本未变时，确认发布后自动执行，不再要求用户逐个平台点击提交。
- 小红书正文与配图不足、MDX 内容无法转换等问题必须在预览中明确呈现。
- 平台内容调整仅影响本次分发稿，不修改 CMS 原稿或其他平台文案。
- 确认发布绑定用户预览过的不可变平台分发稿版本、内容指纹、账号和目标操作；草稿授权不能升级为公开发布，改变操作需要重新确认，未支持操作明确拒绝。另一页面的编辑不能替换已确认内容。分发请求提交后冻结对应快照。当前已有外站副作用、未知结果或活跃任务时拒绝重复创建；仅确定未写入的取消或来源守卫暂停任务，可在新授权与新预览确认后被安全取代。自动更新、撤回和已有外站副本的显式再次分发仍属后续能力，不能换 request_id 绕过判断。

### 4.4 后台展示与操作

- 执行状态和外站状态分开展示，附最后确认时间；结果未知时不能显示已公开。
- 发布记录与日志双向关联，筛选和分页可恢复，空结果、错误、过期数据及无权限明确区分。
- 写操作等待服务端确认，取消、解绑及重新发布说明影响并确认；提交不确定的任务先核对，不能盲目重试。
- 所有页面适配桌面与移动端，支持键盘、可见焦点和减少动态效果；日志与列表刷新不打断阅读。
- 后台及日志接口都要求管理员权限，不能仅依靠前端控制可见性。

## 5. 平台账号与自动化

### 5.1 账号连接

每个账号记录所属平台、平台身份、连接方式、实际可用能力、检查时间及连接状态。

账号状态至少区分：未连接、可用、需要登录、需要验证和暂不可用。登录有效性不能只根据数据库标记判断，执行前必须检查当前平台会话。

官方接口连接需核实应用资质、账号权限和发布能力。登录授权成功或能够读取数据，不等于拥有文章发布权限。

浏览器连接通过平台官方登录页面完成，支持平台提供的扫码等方式；本系统不要求用户向 CMS 提交平台密码或手动粘贴 Cookie。

解除绑定后停止使用该账号的新任务，取消尚未执行的任务，并清理连接凭据；已发布副本记录继续保留。执行中的提交按实际阶段核对结果，不能声称已撤销外站发布。

### 5.2 账号文章只读查看

平台账号统一管理账号与对应文章，默认文章页签，另外提供数据统计和账号设置。平台头像、账号身份与连接状态保持可见；正文使用独立详情，返回恢复筛选和分页，刷新与浏览器前进后退恢复页签。账号设置保留登录检查与远程登录，离开时撤销未完成会话。

CSDN 账号支持主动同步文章与草稿列表、按状态和标题筛选、统计与默认可见的近期趋势图、详情无缓存时自动读取真实正文源文及 CSDN 跳转。数据来自当前已登录账号的官方管理页面，按完整读取保存快照，失败保留已有数据；未知状态独立显示，指标未取得时保留未知。正文读取不创建、修改、删除或发布外站内容；评论仅展示文章评论数量，独立评论管理不在本次交付范围。接口与限制见[API 契约](api.md)。

### 5.3 服务器浏览器

- 浏览器执行器独立运行，不放入 CMS 进程。
- Go 后台调度持久化任务，Node.js 执行器直接调用 Playwright 编程接口，按固定的平台适配代码、状态判断和重试规则执行；Playwright CLI 仅用于开发调试与能力验证，不作为正式调度入口。
- 生产任务不启动 AI Agent，也不调用大模型识别页面或临时生成点击路径。页面结构不符时停止并报告，由开发人员修复适配器后恢复。
- 每个平台账号使用隔离的登录环境和持久化目录，不共用个人日常浏览器目录。
- 同一账号一次只执行一个会修改发布页面的任务。
- 总并发、单步超时和任务执行时间有明确上限，浏览器崩溃后可回收并恢复。
- 页面控件优先通过可理解的名称、标签和稳定结构定位，减少对页面位置和样式类名的依赖。
- 平台页面变化导致无法确认操作对象时停止任务并报告，不能继续猜测点击。
- 临时页面和失败浏览器必须回收；关闭、升级或停止服务时完成进程清理和任务状态保存。
- 不提供任意网址访问或任意脚本执行入口，不实现验证码绕过、设备伪装或账号风控规避。

### 5.4 远程登录与验证

远程浏览器入口必须绑定当前管理员、指定账号和有效时间。当前使用无头浏览器内存画面与受限输入，在后台登录弹窗中完成扫码、短信和拖动验证。入口通过认证后按需开放，退出、超时或验证完成后关闭，不直接暴露浏览器调试端口或无认证的远程桌面。

等待验证时释放执行槽位，允许其他账号的任务继续。等待本身不消耗网络故障重试次数；恢复时先检查外站是否已提交，再决定后续动作。

## 6. 内容与素材适配

### 6.1 通用字段

来源内容包含来源标识、原稿标识、原稿版本、内容指纹、原稿状态、标题、摘要、正文及其格式、标签、封面、素材引用和可选的原文链接。内容指纹由实际用于分发的字段生成，用于区分正文变化和单纯状态变化。

来源标识与原稿标识共同确定一篇原稿。标题、slug 和公开链接只作为展示信息，不能作为唯一身份。

平台分发稿可单独保存标题、正文、标签或话题、封面及配图顺序。平台字段限制应由适配器提供，并在预览、提交和执行前校验。

### 6.2 平台内容形式

| 平台   | 首期适配方向                                   | 必须验证                                         |
| ------ | ---------------------------------------------- | ------------------------------------------------ |
| CSDN   | 技术长文，保留标题层级、代码块、图片和主要结构 | 实际编辑器输入方式、代码与图片展示、必填发布字段 |
| 知乎   | 平台兼容的文章排版                             | 图片、代码、表格、公式及话题的实际支持情况       |
| 小红书 | 独立标题、精简正文、封面和配图                 | 实际账号支持的发布类型、文字与媒体限制、发布结果 |

首期小红书默认以图文笔记作为验证目标，不自动把技术长文截断后发布。文章不适合直接转换时，要求用户在确认分发前编辑平台分发稿。

### 6.3 MDX 与图片

- 通过结构化解析转换正文，不能用简单替换删除所有 MDX 标记。
- 支持的普通段落、标题、列表、链接、代码和图片应保留语义。
- 对自定义组件、交互内容和无法转换的格式显示清单；需要人工调整的内容未处理前阻止该平台提交。
- 外站图片上传到对应平台；不长期依赖 CMS 临时下载地址。
- 来源地址只从已登记的来源和素材域名获取，限制跳转、下载大小、类型和下载时间，阻止读取本机、内网管理地址与云环境凭据地址。
- 素材下载与上传检查实际内容类型、大小及平台限制，不信任文件扩展名。
- 临时素材受访问控制并按保留策略清理，不能进入 Git、前端公开目录或普通日志。

## 7. 任务、状态与可靠性

### 7.1 任务组织

一次分发请求对应一个父任务，每个目标平台账号对应一个子任务。平台之间独立完成或失败，父任务提供全部完成、部分完成、执行中和需要处理等摘要。

执行状态与外站内容状态分别保存，避免将任务提交完成误认为文章已经公开。

| 状态类别     | 至少覆盖                                                     |
| ------------ | ------------------------------------------------------------ |
| 执行状态     | 排队、执行中、等待用户处理、结果核对中、执行完成、失败、取消 |
| 外站内容状态 | 未提交、已提交、审核中、已公开、审核拒绝、已撤回、状态未知   |

外站状态必须附带证据来源与最后确认时间。无法读取审核状态时，展示“已提交，审核状态未知”，不能推断审核通过。

### 7.2 防重复与故障恢复

- 来源提供稳定的请求标识。相同标识、相同内容重复请求返回已有任务；相同标识携带不同内容时返回明确冲突。
- 原稿版本、目标账号和操作类型参与防重复检查，原稿与外站文章之间另存稳定关联。
- 任务领取有互斥、有效期和恢复机制，避免多个执行器同时操作同一任务。
- 临时网络故障采用有上限的退避重试，达到上限后提供人工处理入口。
- 登录与验证问题进入等待处理，不反复尝试登录。
- 发布按钮点击后超时、执行器崩溃或响应丢失时，进入结果核对，先检查创作中心和已有外站记录；不能直接再次提交。
- 提交结果不确定时后台自动读取平台记录核对；完整匹配直接完成，可靠确认未提交后有限重试。读取失败需自动复查；冲突或预算耗尽明确报错，人工核对仅作兜底，不以必须手填外站 ID 作为常规恢复流程。
- 进程重启后恢复排队和可安全恢复的任务，保留已完成的平台结果。

防重复目标是约束本系统重复请求、重复领取和盲目重试。平台不提供可靠提交查询或去重能力时，不能承诺任何情况下都绝对不会重复，必须保留结果不确定状态。

### 7.3 发布与审核

点击按钮、上传完成、进入草稿箱或收到任务响应，均不能单独作为发布成功依据。适配器需确认平台已接受发布提交，并记录可获得的外站文章标识和链接。

能自动查询审核结果的平台应继续更新状态；平台无法提供可靠证据时明确显示未知，不影响已确认的提交事实，也不冒称已公开。

## 8. 原稿生命周期与外站副本

| 来源操作           | 首期规则                                                     |
| ------------------ | ------------------------------------------------------------ |
| 草稿修改           | 不创建自动发布任务                                           |
| 明确选择平台并发布 | 使用用户确认的版本创建分发任务                               |
| 原稿再次编辑       | 不自动覆盖快照；尚未外站提交且内容已变化时暂停，要求重新预览和提交；已提交副本保持原结果 |
| 下架或转私有       | 取消尚未提交的任务，执行器在外站提交前再次检查原稿状态       |
| 修改后再次发布     | 已有外站副本默认不自动再创建；提示关联副本及其版本           |
| 删除原稿           | 取消未提交任务，保留外站关联和处理提示，并按策略清理内容快照 |

首期先完成新增发布。外站已有副本的自动更新与自动撤回不作为首期保证能力；用户需在对应平台处理，本系统提供链接和人工核对记录。当前不支持已有外站副本的显式再次新建；无外站副作用的取消或来源守卫暂停任务可按新授权与新确认安全取代，具体服务端条件见外部手册。新 request_id 不能绕过重复保护。

来源通知有事件标识和可比较的单调递增顺序号，重复事件不重复执行，较旧事件不能覆盖较新状态。平台文案编辑与来源生命周期通知分别处理。

外站提交前无法确认原稿仍允许分发时，任务暂停。检查与外站提交之间仍存在短暂竞争窗口；已经在外站生效的副本不能凭来源状态自动认定撤回。下架、设私有和删除结果均需提示外站副本的实际状态。

## 9. CMS 对接契约

### 9.1 连接方式

CMS 是内容编辑、选平台和确认分发的主入口；本系统提供平台稿预览、独立调整、账号验证及异常处理入口。双方职责与剩余改造见[CMS 总体方案](cms-integration.md)；PostBridge 当前可用的草稿来源协议已落实到[外部手册](external-integration.md)及[OpenAPI](../contracts/cms.openapi.yaml)。CMS 代码、双方共同审阅和实际连接仍待，D01 整体及完整 D04 未完成。后台顶部提供有名称的文档图标，打开站内接入手册；阅读页支持章节跳转、窄屏表格和契约、测试向量下载，与仓库文档保持同一来源。

两个系统可部署在不同服务器及内网，通过 HTTPS 服务端接口连接。调用平台必须先经受邀注册、管理员审批、独立凭据签发与激活；两向调用分别登记，每次请求校验应用状态、签名、来源和接口权限。未注册、未审批、未激活、过期、暂停或撤销的身份不能访问业务接口，同内网或 IP 白名单不代替认证。CMS 业务浏览器不得持有来源连接密钥，注册响应不返回业务凭据。管理员一次签发仅临时显示密钥，关闭或离开清空，不进入前端持久存储。

CMS 仅需获取平台能力、提交分发请求、可靠通知原稿状态和查询任务摘要。首期由 CMS 轮询任务摘要，详细状态在本系统查看，避免同时引入多套结果回调机制。

### 9.2 对接操作

| 操作           | 最少要求                                                     |
| -------------- | ------------------------------------------------------------ |
| 获取发布目标   | 返回稳定的平台与账号标识、连接状态、可用能力和校验要求，不返回凭据 |
| 准备分发稿     | 接收允许外传的内容快照，生成平台预览；未确认前不执行外站发布 |
| 提交分发       | 携带请求标识、原稿身份、正式发布版本、确认内容指纹、不可变的平台分发稿版本标识和选定账号，快速返回任务标识 |
| 查询结果       | 返回父子任务摘要、需处理事项、已确认的外站状态及链接         |
| 通知原稿状态   | 接收下架、转私有和删除等事件，处理重复和乱序事件             |
| 执行前状态确认 | 按原稿身份查询其当前状态和版本，确认是否仍允许提交           |

### 9.3 原稿权限与预览

私有文章、未授权草稿及其素材不得发送到分发系统。为了支持正式发布前预览，CMS 可以在用户主动勾选平台并请求预览时，明确授权发送本次草稿快照；该授权仅用于生成分发稿，不代表允许外站发布。

只有 CMS 确认站内发布成功、分发内容与确认快照一致，并提交正式分发请求后，任务才可执行。确认期间内容变化时要求重新预览，不接受过期内容直接发布。CMS 若在发布时因状态更新递增文章版本，允许提交正式发布版本与预览版本不同，但必须校验内容指纹一致；状态顺序号、文章版本和内容指纹分别记录。执行前需同时确认当前为已发布状态且内容仍与任务一致。

预览授权撤销、文章转私有或预览到期后，清理未提交的分发稿和素材。到期时间应可配置，初始化时确定默认值并记录在运维文档。

### 9.4 CMS 项目承担的改动

- 发布弹窗提供可选平台、连接状态和预览入口。
- 后端发送经过字段筛选的内容快照，不传后台私有字段、用户凭据或无关修订。
- 站内发布与待发送分发通知在本地同一事务落库，提交后再进行网络调用。
- 站内发布成功但分发暂未接收时，保留待发送状态并重试，准确提示用户。
- 将下架、转私有和删除通知可靠持久化并发送。
- 提供受认证的执行前原稿状态检查接口。
- 展示任务摘要和详情入口，允许用户选择只发布自有博客。

本系统不可用时，CMS 自有博客发布功能仍可正常使用；用户选中的分发意图保留为待发送，而非静默丢失。

## 10. 数据、安全与运维

### 10.1 逻辑数据

至少包含调用应用、邀请与审批、独立凭据版本及权限、内容来源、平台账号、来源原稿引用、不可变内容快照、平台分发稿、父子任务、执行尝试、外站副本和管理员操作记录。

连接凭据与浏览器会话受专门保护；任务日志不包含密码、Token、Cookie、验证码或完整登录页面内容。不得将密钥、真实账号状态、截图和素材作为仓库示例提交。

### 10.2 权限与审计

- 管理接口、任务内容、素材、截图和远程浏览器入口均需认证与权限检查。
- 调用应用先注册、审批和激活，来源凭据只访问接收方批准的来源、接口、账号及操作；不得自行扩大权限，也不获得管理员登录或浏览器控制权限。
- 记录应用注册、审批、签发、激活、权限修改、停用、拒绝访问、账号绑定、正式提交、取消、重试、人工确认及凭据轮换；秘密只在安全签发时交付一次。
- 失败截图与诊断记录仅在必要时保存，限制访问和保留期限，避免记录验证码和敏感登录信息。
- 安全措施覆盖请求重放、跨站请求伪造、正文预览脚本注入、任意地址读取和会话泄露。

### 10.3 部署与运行

建议采用 Go 服务端、React 与 TypeScript 后台、Node.js 与 Playwright 浏览器执行器、PostgreSQL，以及 Docker Compose 部署。工具版本在项目初始化时核实并固定；不将 CMS 的具体版本要求自动套用到独立项目。

首期可以部署在 CMS 同一台服务器，使用独立服务、数据库权限和持久化目录，并限制 CPU、内存、浏览器并发、日志和素材占用。具备拆迁至独立服务器的条件，不依赖 CMS 的容器内部地址或私有代码路径。

必须能查看任务积压、持续失败、等待验证、执行器离线和磁盘占用。首期在后台显示提醒，不强制接入邮件、短信等外部通知渠道。

部署前明确有限重试次数、退避间隔、步骤超时、任务执行上限、远程会话有效期、未提交预览期限、素材及诊断记录保留期限。参数应有安全默认值和上限，不允许无限重试或无限保留。

数据库、必要的会话文件和加密密钥分别按受限策略备份，完成恢复演练；仅备份数据库不足以恢复全部连接。升级前备份数据，服务停止时释放浏览器和执行锁，恢复后先核对中断任务结果。

### 10.4 后台日志查询

任务执行、系统运行和管理员操作日志在后台统一检索，字段、查询限制及刷新行为见[管理后台与界面规范](admin-ui.md)。服务端负责权限检查、脱敏、分页和查询范围限制，禁止返回凭据、文章正文或可执行页面内容。来源连接凭据不得访问日志接口。

日志仅供读取和定位问题，不开放任意文件读取、命令执行或原始日志下载。保留期限有明确上限，在部署时固定并按策略清理；记录过期时向管理员说明。后台离开、隐藏或会话失效后停止无用刷新。

## 11. 阶段规划

| 阶段            | 交付物                                               | 通过条件                                                     |
| --------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| A：平台能力验证 | 三个平台的账号资格、发布方式、登录及审核结果识别报告 | 在计划部署环境用明确授权的账号验证真实发布，列明阻塞、能力边界和素材要求 |
| B：独立系统基础 | 独立后台、来源、账号、受保护的远程登录、持久化任务及日志查询   | 无 CMS 依赖可通过测试来源执行任务；发布记录、日志查询、权限、重启恢复和进程清理通过 |
| C：平台发布闭环 | 三个平台适配器、内容转换、上传、提交和结果记录       | 每个平台独立完成真实发布和关键异常验收，可分批交付，不合并虚报进度 |
| D：CMS 对接     | 通用契约、CMS 薄连接器联调、预览与生命周期通知       | 逐篇勾选、关闭电脑继续执行、部分成功、可靠投递和隐私隔离通过 |
| E：上线与运维   | 部署、备份恢复、监测、排障和验收记录                 | 生产环境完成明确授权的真实链路验证，所有必要能力有证据       |

建议先验证 CSDN，再验证知乎和小红书，实际顺序由阶段 A 的结果决定。完成能力验证前不承诺三平台稳定性、资源容量或工期。

真实账号登录、公开测试文章和清理外站测试内容均在明确授权范围内执行，开发测试默认使用模拟适配器，不在 CI 自动公开发文。

## 12. 首期验收清单

以下均为待验收，不能凭代码合入、页面可见或模拟测试通过直接勾选。

- [ ] 独立部署运行，无需启动 AI Agent、连接大模型服务或配置模型密钥；CMS 不共享数据库、登录密钥和平台凭据。
- [ ] 独立后台可查看总览、发布记录和任务详情，筛选分页、状态语义及最后确认时间正确。
- [ ] 日志中心可查询任务、系统和操作日志，脱敏、权限、范围限制、分页及任务跳转通过。
- [ ] 所有前端按两个项目设计技能完成审阅，桌面、移动端、键盘及减少动态效果检查通过。
- [ ] 后台加载、空结果、异常、会话失效和数据过期提示正确，停止刷新后无残留轮询。
- [ ] CSDN、知乎、小红书分别具备真实账号与计划部署环境的发布证据。
- [ ] 用户确认平台分发稿后，服务器自动上传并提交，无需逐个平台人工点击发布。
- [ ] 用户关闭电脑、退出后台或刷新页面后任务继续，结果可再次查询。
- [ ] 账号失效和验证码场景可安全进入远程处理，处理后任务继续且不重复提交。
- [ ] 平台分别显示执行结果和审核状态，只有证据充分时显示已公开。
- [ ] 三平台部分失败时保留成功结果，仅处理失败或待核对的平台。
- [ ] 重复请求、重复领取和服务重启不会导致已确认的任务重复发文。
- [ ] 发布提交后超时进入结果核对，证据不足时不自动再次提交。
- [ ] 原稿内容变化后尚未提交的任务暂停并要求重新预览；平台分发稿跨页面编辑不能替换已确认版本。
- [ ] MDX 不兼容内容可见，代码、表格、公式和图片按每个平台实测结果验收。
- [ ] 私有内容不会未经授权外传，下架和转私有能阻止尚未提交的分发。
- [ ] 原稿通知重复和乱序时状态正确，外站副本撤回情况如实展示。
- [ ] CMS 与分发系统短暂断网后能恢复投递，博客发布正常且分发意图不丢失。
- [ ] 登录环境与账号隔离，远程入口、素材和诊断文件无法匿名访问。
- [ ] 素材地址、正文预览和接口参数的边界、异常与越权路径得到验证。
- [ ] 浏览器崩溃、任务取消、服务停止和失败清理后无临时进程、页面或执行锁残留。
- [ ] 队列积压、账号需处理、磁盘占用和持续失败可在后台发现。
- [ ] 数据与会话恢复、凭据轮换、升级和中断任务恢复完成演练。
