# 总体进度

## 当前交付

已实现单管理员、单 CSDN 账号的文字 Markdown 草稿后台。管理界面包含登录、总览、草稿创建与预览、任务详情、账号检查、弹窗远程登录、账号文章只读列表、统计、正文查看和对象处理记录；Go API 持久化任务，独立 Node.js/Playwright 进程执行，不依赖 AI Agent、模型服务或模型密钥。

任务具备请求去重、账号串行、租期和心跳、有限安全重试、取消、登录后继续、自动查询草稿、只读正文核对与可选人工结束。无 ID 的超时任务自动读取全部草稿分页，连续两次完整空结果后有限重试；查询冲突或耗尽明确报错，不要求用户常规手填 ID。未知结果禁止盲目新建；草稿 ID、内容与状态核对通过才记为保存成功。Ubuntu 安装与服务运行见[部署说明](ubuntu-deployment.md)。运行和异常处理见[开发说明](development.md)、[API 契约](api.md)及[运维说明](operations.md)。

平台账号统一展示账号与文章，默认“文章”，另设“数据统计”和“账号设置”；正文保持独立，返回恢复筛选和分页，刷新及浏览器前进后退恢复页签。界面仅保留内容、操作、表单和必要状态；模块说明已清理。远程登录在弹窗内完成，支持键盘焦点循环、Escape 关闭及会话清理。

对象处理记录按一次提交展示平台、账号、对象、操作和结果；详情包含完整状态流转、逐轮事件及实际字段前后对比。不同提交分别保留，重试和只读核对归入原流程。内容快照单独受保护，未采集值明确标记，已有事件缺少状态时仍显示实际步骤与时间；文章更新执行与 CMS 对接仍待实施。

## 账号文章只读范围

“平台账号”的文章页签提供文章列表、标题搜索、已发布／草稿／未通过／回收站／未知状态筛选、分页，以及独立正文与元数据查看、固定 CSDN 链接；数据统计页签提供账号汇总与近期趋势。管理员主动同步，页面轮询只读取本地快照；失败保留已有数据，未知状态不推断审核结果。

读取与草稿任务共用账号租约和浏览器锁，按任务账号与文章 ID 校验；保存、删除及发布请求在只读浏览器中阻断。文章编辑、删除和公开发布管理不在本次交付中。具体证据见[验收记录](acceptance.md)。
