# 总体进度

## 当前交付

已实现单管理员、单 CSDN 账号的文字 Markdown 草稿后台，包含账号检查与弹窗远程登录、账号文章只读列表和统计、正文查看、对象处理记录、持久队列、账号互斥、有限安全重试与未知结果核对。API、后台和固定 Playwright 执行器独立运行，不依赖 AI Agent 或模型密钥。

PostBridge 侧外部来源接入已实现：受邀注册、审批、一次性密钥、签名激活与调用、权限和轮换、来源事件、不可变平台稿修订与确认、父分发查询、实时来源守卫及重新确认后恢复原任务。后台“内容来源”提供平台稿、分发记录、应用、申请、邀请和审计。顶部文档图标进入站内接入手册，支持章节目录、窄屏表格及契约与向量下载，内容直接取自现行 Markdown。协议见[外部手册](external-integration.md)、[OpenAPI](../contracts/cms.openapi.yaml)，职责与调用方剩余见[CMS 总体方案](cms-integration.md)。

当前来源执行仅开放 CSDN 文字 Markdown save_draft；公开发布、图片、MDX、其他平台、自动更新或撤回平台文章、已有外站副本的显式再次新建仍未交付。存在副作用、未知结果或活跃任务时拒绝重复；确定未写入的取消或来源暂停任务，允许新授权与新确认后的安全替代，换标识不能绕过服务端判断。

## CMS 与真实平台边界

CMS 仓库未修改。CMS 发布选择、后端确认核对、事务发件箱、反向身份与权威状态服务，以及实际连接和联合验收仍待实施。PostBridge 侧本地验证不能关闭 D01 整体、D04 或三平台首期。

既有真实 CSDN 账号登录、草稿保存、完整文章与草稿只读同步、统计趋势及正文核对已有证据。用户指定的一篇既有草稿经官方表单公开提交并读回已发布，用户无痕确认公开阅读；自动化公开页仍受 WAF 限制。这不代表后台自动公开发布或本次外部 CMS 到真实草稿链路已经通过。

平台账号和处理记录的具体交付、真实证据继续见[验收记录](acceptance.md)与[平台能力](platform-capabilities.md)。
