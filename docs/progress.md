# 总体进度

## 当前交付

全仓代码审阅与规范格式化已纳入维护：纯文本 CSDN 草稿只允许已确认的草稿写入，自动保存也检查草稿状态，写入不跟随重定向；后台处理无效编码路由与严格模式操作清理。Go 依赖修复、验证范围及仍待验边界见[代码质量与安全](code-quality.md)。

项目 Go 工具链统一为 1.26.10，模块、本地启动器、服务器安装器和 CI 保持一致。本地 WSL 开发与 Ubuntu 部署统一提供 Shell 入口，复用 Python 管理逻辑；两份操作手册逐步列出环境准备、初始化、启动、停止、备份升级和检查命令，区分本地独立数据库与服务器专属数据库的管理边界，见[开发说明](development.md)与[Ubuntu 部署](ubuntu-deployment.md)。

已实现多用户独立登录、同平台多账号的 CSDN 与小红书平台账号工作台，以及 CSDN Markdown 草稿后台，包含账号检查与弹窗远程登录、账号文章只读列表和统计、正文查看、对象处理记录、持久队列、账号互斥、有限安全重试与未知结果核对。API、后台和固定 Playwright 执行器独立运行，不依赖 AI Agent 或模型密钥。

PostBridge 侧外部来源接入已实现：受邀注册、审批、一次性密钥、签名激活与调用、权限和轮换、来源事件、不可变平台稿修订与确认、父分发查询与主动取消、本地快照授权守卫及重新确认后恢复原任务。后台“内容来源”提供平台稿、分发记录、应用、申请、邀请和审计。顶部文档图标进入站内接入手册，支持章节目录、窄屏表格及契约与向量下载，内容直接取自现行 Markdown。协议见[外部手册](external-integration.md)、[OpenAPI](../contracts/cms.openapi.yaml)，职责与调用方剩余见[外部接入总体方案](cms-integration.md)。

来源执行操作为 CSDN Markdown save_draft。开启图源配置后，支持通过 CSDN 转存合规的正文图片并保存草稿。账号预设与单篇修改随平台稿修订确认。图文与发布预设的验收见 [CSDN 图文与发布预设](plans/csdn-rich-publishing.md)。管理员可在平台任务中从已核对的 CSDN 集成草稿发起独立发布。发布任务填入已确认选项，提交后只读核对原稿。真实平台发布验收、MDX、知乎及小红书写入、自动更新或撤回及显式再次新建仍待。存在副作用、未知结果或活跃任务时拒绝重复；确定未写入的取消或来源暂停任务，允许新授权与新确认后的安全替代，换标识不能绕过服务端判断。

## 用户与账号隔离

已实现管理员创建与停用普通用户、独立密码登录和会话撤销；每个用户可绑定多个 CSDN 或小红书账号，平台身份核验后建立独占归属，不支持共享或转让。账号、任务、文章、日志、统计及来源授权使用所属用户隔离，执行器使用独立连接凭据、会话目录与浏览器沙箱。

已有账号和业务数据在初始化事务中归入当前初始化管理员，保留标识、内容、请求去重和平台会话；重复启动不重复迁移。解绑停止新任务、撤销连接并清理凭据，保留历史；未确认平台结果须先核对，不能用解绑绕过。迁移和认证位置见[账号归属与认证存储](account-ownership.md)。本地业务环境已完成受限备份、恢复演练和实际升级，原管理员登录、已有数据读取与 CSDN 会话只读检查通过；已有小红书会话已导入同一管理员并通过只读检查。恢复副本上的双用户、同平台多账号与并发隔离通过，未向业务库添加测试用户或账号。具体证据见[验收记录](acceptance.md)，同平台多个真实账号和生产迁移尚未验收。

## 小红书接入

已实现[平台账号管理](platform-accounts.md)、小红书登录检查和笔记只读列表，并接入现有后台。每个用户可绑定同平台多个账号；按独立凭据领取任务、锁定专属会话，执行前后核对小红书号与稳定用户标识。服务端拒绝跨账号上报，列表完整读取后原子替换，失败、取消或失租保留旧快照。

当前本地管理员已接入已有小红书会话，接入前受限备份并保留原会话与 CSDN 数据。正式 API／执行器登录检查、两次笔记只读同步及后台跨平台账号切换、键盘、刷新和窄屏验证通过；原生列表为空，非空笔记和分页仍待真实样例。未发布、编辑或删除平台内容，业务服务继续运行。

非空条目、分页、重复检测和结构异常仅合成数据通过，仍待真实有笔记账号验收。缺失统计与未知状态不推断。不提供笔记正文、素材上传、远端草稿、发布、编辑或删除；未执行这些操作。图文及发布完整关口、A04/C06 和生产均未完成。

官方笔记管理的四类状态筛选空结果及图文上传前页面也已只读检查。页面提示支持 JPG、JPEG、PNG、WebP、多选和单张最大 32MB；这些提示不代表实际上传可用。上传初始化探测和许可请求已阻断，标题、正文、话题、封面与实际素材边界仍待验。

停用账号的接口与任务守卫、旧链接返回路径，以及原生分页请求与点击的绑定均已实现并通过回归；代码和用例保持正常换行格式。

本地定向验证覆盖数据库账号隔离、幂等、取消、失租与快照保留，执行器只读网络策略、身份异常和分页，后台切换、搜索、分页与窄屏。代码与文档通过 PR 检视维护；临时验证脚本、原始响应和账号配置不提交。详见[验收记录](acceptance.md)。

## 调用方与真实平台边界

PostBridge 按固定接口和认证独立运行，任意调用方只需配置授权，无需提供反向服务、先发来源事件或修改 PostBridge。人工预览确认仍是当前执行策略；来源事件是可选主动通知，结果使用轮询，Webhook 尚未实现。CMS 或其他真实调用方的连接器、确认核对、可靠发送及联合验收仍待；事务发件箱只是调用方内部建议。本地验证不能关闭真实调用方关口、完整 D04 或三平台首期。

既有真实 CSDN 账号登录、草稿保存、完整文章与草稿只读同步、统计趋势及正文核对已有证据。用户指定的一篇既有草稿经官方表单公开提交并读回已发布，用户无痕确认公开阅读；自动化公开页仍受 WAF 限制。这不代表后台自动公开发布或本次外部 CMS 到真实草稿链路已经通过。

平台账号和处理记录的具体交付、真实证据继续见[验收记录](acceptance.md)与[平台能力](platform-capabilities.md)。
