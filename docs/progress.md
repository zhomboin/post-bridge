# 总体进度

## 当前交付

已实现单管理员、单 CSDN 账号的 Markdown 草稿后台，包含账号检查与弹窗远程登录、账号文章只读列表和统计、正文查看、对象处理记录、持久队列、账号互斥、有限安全重试与未知结果核对。API、后台和固定 Playwright 执行器独立运行，不依赖 AI Agent 或模型密钥。

PostBridge 侧外部来源接入已实现：受邀注册、审批、一次性密钥、签名激活与调用、权限和轮换、来源事件、不可变平台稿修订与确认、父分发查询与主动取消、本地快照授权守卫及重新确认后恢复原任务。后台“内容来源”提供平台稿、分发记录、应用、申请、邀请和审计。顶部文档图标进入站内接入手册，支持章节目录、窄屏表格及契约与向量下载，内容直接取自现行 Markdown。协议见[外部手册](external-integration.md)、[OpenAPI](../contracts/cms.openapi.yaml)，职责与调用方剩余见[外部接入总体方案](cms-integration.md)。

来源执行操作为 CSDN Markdown save_draft。开启图源配置后，支持通过 CSDN 转存合规的正文图片并保存草稿。账号预设与单篇修改随平台稿修订确认。图文与发布预设的验收见 [CSDN 图文与发布预设](plans/csdn-rich-publishing.md)。管理员可在平台任务中从已核对的 CSDN 集成草稿发起独立发布。发布任务填入已确认选项，提交后只读核对原稿。真实平台发布验收、MDX、其他平台、自动更新或撤回及显式再次新建仍待。存在副作用、未知结果或活跃任务时拒绝重复；确定未写入的取消或来源暂停任务，允许新授权与新确认后的安全替代，换标识不能绕过服务端判断。

## 调用方与真实平台边界

PostBridge 按固定接口和认证独立运行，任意调用方只需配置授权，无需提供反向服务、先发来源事件或修改 PostBridge。人工预览确认仍是当前执行策略；来源事件是可选主动通知，结果使用轮询，Webhook 尚未实现。CMS 或其他真实调用方的连接器、确认核对、可靠发送及联合验收仍待；事务发件箱只是调用方内部建议。本地验证不能关闭真实调用方关口、完整 D04 或三平台首期。

既有真实 CSDN 账号登录、草稿保存、完整文章与草稿只读同步、统计趋势及正文核对已有证据。用户指定的一篇既有草稿经官方表单公开提交并读回已发布，用户无痕确认公开阅读；自动化公开页仍受 WAF 限制。这不代表后台自动公开发布或本次外部 CMS 到真实草稿链路已经通过。

平台账号和处理记录的具体交付、真实证据继续见[验收记录](acceptance.md)与[平台能力](platform-capabilities.md)。
