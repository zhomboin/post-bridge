# 管理后台与界面规范

## 定位与范围

后台供单名管理员检查文章分发、处理异常和查看日志，独立于 CMS 登录与部署。界面以中文为主，服务日常发布管理，不引入团队、收费或内容生成能力；账号统计仅展示平台返回的数据。本文确定完整页面与验收要求。当前提供管理员登录、总览、CSDN 草稿任务与详情、对象处理记录、账号检查、弹窗远程验证及账号文章只读列表、统计和正文；系统设置由 API 只读提供。页面实现见 [apps/admin/src](../apps/admin/src)，接口见[API 契约](api.md)。PostBridge 侧来源应用管理、平台稿确认和分发聚合已实现；真实调用方连接、三平台发布和完整系统配置编辑继续待实施。

所有前端页面、组件、交互及界面审阅必须共同遵循 [Frontend Design](../.agents/skills/frontend-design/SKILL.md) 与 [Emil Kowalski 设计工程技能](../.agents/skills/emil-design-eng/SKILL.md)。安装来源见[前端技能说明](frontend-skills.md)。

## 模板选择与视觉方向

采用清晰、紧凑的发布工作台：左侧导航、顶部页面标题与筛选、主体列表、独立任务详情。主要参考 [shadcn/ui Dashboard](https://ui.shadcn.com/blocks?category=dashboard) 的信息组织和 [Sidebar](https://ui.shadcn.com/docs/components/sidebar) 的可折叠导航。仅参考适合本业务的结构，不整套复制示例中的图表、指标和配色。

默认浅色，背景为冷灰、内容面为白色，蓝色用于主要操作；深灰文字保证长时间阅读。统一使用六个基础色：背景 #F6F8FA、内容 #FFFFFF、文字 #182230、边界 #D8DEE8、主色 #2557C8、次要文字 #526176。状态色另外按成功、警告、失败定义，并始终配合文字说明。主题颜色需在实际实现时检查对比度。

中文优先使用思源黑体及系统中文字体回退；标题和正文共用字族，以字号、字重和留白区分层级。等宽字体只用于任务标识和日志详情。内容左对齐，采用 4 像素间距单位、6 至 10 像素圆角和细分隔线。突出“需要处理”的队列与平台结果，不堆砌卡片、装饰图表或渐变效果。深色主题不作为首期必交付项。

## 页面组织

界面只保留必要的标题、按钮、文章、图片、表单项、状态、错误和操作确认，不展示模块介绍、功能说明及操作教学段落。限制在字段标签或校验反馈中表达，使用方式写入开发文档。

| 页面 | 内容与操作 |
| --- | --- |
| 登录 | 管理员登录、退出及会话过期提示 |
| 总览 | 当前排队、执行中、失败、待验证和待核对任务；账号异常与执行器健康提醒；每项提醒可跳转筛选结果 |
| 发布记录 | 按文章聚合父任务，展开查看平台子任务；按标题或任务标识搜索，并按来源、平台、账号、执行状态、外站状态和时间筛选 |
| 任务详情 | 原稿身份与快照版本、确认内容、各平台执行状态、外站状态及链接、最后确认时间、尝试记录与关联日志 |
| 处理记录 | 按对象的一次提交显示平台、账号、操作、状态和最终结果；点击查看状态流转、字段前后差异和完整日志；同一对象多次处理各占一条 |
| 分发稿 | 查看来源快照、分平台预览和修改、兼容性提示及确认提交 |
| 平台账号 | 共享账号身份、连接状态与同步时间；默认文章页签，另外提供数据统计和账号设置；正文使用独立详情页 |
| 内容来源 | 调用应用登记、状态、权限及凭据轮换 |
| 验证处理 | 受保护的临时远程浏览器入口与处理状态 |
| 系统设置 | 并发、超时、有限重试、保留期限、健康状态和展示时区 |

发布记录列表至少显示文章标题、来源、目标平台、任务摘要、创建及更新时间。任务详情作为固定链接的独立页面；轻量预览可以使用侧栏，不能只依赖弹窗保存完整上下文。

## 外部来源工作台与界面审阅

当前“内容来源”包含平台稿、分发记录、应用、申请、邀请和审计六个页签。页签、状态筛选和分页保存在地址中；平台稿详情独立显示来源原稿和目标稿，保存新修订后需重新确认。已提交或过期稿只读，预览不执行 HTML、不加载正文图片。

应用审批和轮换的密钥只在此次响应后的临时弹窗显示，关闭、离开或隐藏清空，不写入地址和前端持久存储。授权表单只包含来源标识、权限、账号、操作、有效期和请求上限。写操作等待服务端确认，轮换、暂停、撤销和恢复都有明确确认，不因轮询重复显示密钥。

来源暂停需同时具有父分发标识和来源错误码，显示“来源待处理”及“处理来源授权”，不提示平台登录或普通恢复；实际账号登录仍走账号设置。父分发仅在服务端允许恢复时提供重新确认入口，unknown/reconciling 继续只读核对。

按项目内两个技能检查最新版 1440、390、320 像素、键盘页签、弹窗焦点循环与返回、Escape 关闭、减少动态效果及长内容换行。合成截图不含真实账号、地址或签发密钥。

## 平台账号工作台

主导航统一为“平台账号”。账号头部显示平台头像、昵称、账号 ID、连接状态与最近同步时间；当前使用一个 CSDN 账号，不增加未实现的账号切换或绑定操作。

| 页签 | 当前内容 |
| --- | --- |
| 文章 | 默认打开；同步文章、标题与状态筛选、20 条分页、正文入口 |
| 数据统计 | 平台汇总指标与默认可见的六项按日趋势图；缺失值不补零，各图独立刻度 |
| 账号设置 | 登录状态检查、检查时间与错误、弹窗远程登录 |

页签、筛选和分页写入地址，切换页签、刷新与浏览器前进后退保留状态；重新筛选从第一页开始。正文继续使用独立详情，返回恢复账号文章页及原筛选分页。无缓存时自动读取一次，失败或取消后由管理员手动重试；优先直接显示 Markdown 源文，仅有 HTML 时显示 HTML 源文，不执行内容。等待登录的任务进入账号设置，账号检查任务也返回设置页签。离开账号设置卸载远程登录，撤销未完成会话并停止画面与输入请求。页签支持键盘、可见焦点和窄屏。

头像仅从固定 CSDN 头像域加载，禁止发送来源信息，加载失败显示占位；其他封面与正文图片不自动请求。趋势图支持键盘读取日期和值，单点、负数与缺失值按实际数据展示，窄屏单列显示。

## 发布信息与异常处理

- 执行状态与外站内容状态分开展示。“执行完成”不等于“已公开”；未知审核结果保留未知，展示证据来源和最后确认时间。
- 部分平台失败时保留成功结果，仅对允许恢复的子任务提供操作。等待登录、验证、结果核对和普通失败分别给出原因与下一步。
- 提交结果不确定时只能进入核对流程，不能通过通用“重试”直接再次发文。重新发布、取消和解绑等影响任务的操作需说明范围并确认。
- 服务端校验权限、内容版本及允许的状态转换，按钮隐藏或禁用不能替代校验。写操作等待服务端确认，不乐观显示“发布成功”。
- 筛选与分页可恢复，详情返回列表时保留上下文；账号凭据和敏感内容不能写入地址参数。

## 日志查看

默认列表以一次提交为一条处理记录，同一任务的安全重试、登录恢复和只读核对保留在该记录内。同一对象再次提交生成新记录，不按同标题合并不同文章。文章使用平台草稿标识，无平台标识时使用任务标识；账号使用平台账号标识。当前执行能力包括新建草稿、账号检查、文章同步与正文读取，文章更新执行和实际 CMS 连接待实施；当前来源草稿父分发另由“内容来源”的分发记录查看。

处理详情展示对象、平台、账号、操作及最终结果。状态流转图按实际事件分轮次展示，并标出只读核对与当前节点；完整流转独立于日志分页，已有事件缺少状态时继续展示实际步骤和时间，并标明状态未采集，不补造状态。任务详情也提供相同流程。

标题、正文及账号状态在独立受保护快照中记录，按字段显示处理前后差异；可切换整体或单轮执行。正文按需读取，长内容可展开，按纯文本显示。没有实际采集的值显示“未采集”，真实空值显示“（空）”，不将任务期望内容作为平台实际值。全部日志保留平铺查询入口。

| 视图 | 必要字段 |
| --- | --- |
| 任务执行 | 时间、平台与账号展示名、父子任务标识、尝试次数、执行步骤、级别、脱敏摘要与错误原因 |
| 系统运行 | 时间、服务或执行器、级别、关联标识、脱敏事件摘要；关联任务时可跳转 |
| 管理员操作 | 时间、操作者、操作类型、目标标识和结果；包括提交、取消、重试、人工核对及凭据轮换，不记录凭据本身 |

按时间、级别、平台、任务标识及关键词组合查询；只展示当前视图适用的筛选项。处理记录、日志与发布记录均由服务端分页，默认每页 50 条，上限 100 条；列表时间范围默认最近 24 小时，单次查询上限 31 天；处理详情始终查询本任务保留期内的完整日志，不受列表时间筛选限制。内容超长时先显示摘要，再按需加载详情，不一次加载完整日志。

活动任务与日志采用有上限的轮询，默认每 5 秒刷新，支持暂停和手动刷新。用户关闭自动刷新、页面隐藏、退出页面或会话失效时停止轮询，恢复可见后按设置刷新。显示最后更新时间和断连提示；失败时保留已有内容并标明可能过期，退避重试，不并发堆积请求。

查看日志时不强制滚动到底部；用户开启跟随后才滚动，暂停时提示有新记录。查询结果为空、时间范围超出保留期限、无权限和服务异常必须区分说明。

日志从写入、查询到展示均脱敏，不含密码、Token、Cookie、验证码、登录页面或文章正文。只允许受认证管理员访问；来源凭据不得查询日志。内容按纯文本展示，禁止执行 HTML 或脚本。首期不提供原始文件下载、任意文件读取、终端或脚本入口；日志和诊断文件按有限保留策略清理，具体期限在部署文档中固定。

## 交互、适配与审阅

- 动效用于反馈状态，常用切换和键盘操作即时响应。偶发抽屉、菜单反馈以 150 至 250 毫秒为参考，避免回弹、整页重复入场和日志刷新动画。
- 优先只动画变换与透明度，禁止笼统过渡全部属性；可中断交互需自然衔接。尊重减少动态效果设置，触摸设备不依赖悬停。
- 支持键盘导航、可见焦点、表单标签、图标按钮名称、弹层焦点管理及关闭后焦点恢复。普通文字对比度至少 4.5:1；状态不能只靠颜色表达。
- 桌面优先提高列表与日志阅读效率；移动端收起侧栏，将表格改为摘要列表或局部横向滚动。保留状态查看、日志筛选、验证和异常处理入口，不让整页横向溢出。
- 长标题、空列表、加载、失败、权限不足、会话失效、陈旧数据和大量日志均需设计对应状态。加载占位避免明显跳动。
- 每次前端变更先明确布局与样式规则，再按两个技能审阅。审阅记录使用“调整前／调整后／原因”表格，通过文件路径定位实现，不在文档嵌入代码。

## 验收范围

本地验证受影响的筛选、分页、日志与任务关联、只读访问、写操作确认和请求清理；覆盖超长字段、空结果、失败恢复、会话失效及日志脚本内容。前端建立后补充关键流程自动化，GitHub CI 承担全量验证，不访问真实发布账号。

界面验收至少检查桌面 1440 像素、移动端 390 像素及 320 像素窄屏，核对键盘操作、减少动态效果、状态文案和脱敏数据。截图使用模拟数据，不能将后台页面可见等同于真实发布验收完成。

## 远程验证交互

平台账号的账号设置页签显示等待、活动、成功、超时和失败状态。画面按原始视口映射点击和拖动，手机号和短信验证码提供明确的填写按钮，定位认证窗口内唯一可用字段；填写成功后提示下一步，发送后立即清空本地内容。获取短信与确认登录仍在官方画面操作；所有输入按顺序提交。登录画面置于居中弹窗，内容过长时在弹窗内滚动；Tab 可离开画面并在弹窗内循环，Escape 关闭弹窗并返回入口，“下一输入框”在认证窗口的可见输入间循环，不经过背景链接。关闭弹窗或离开页面停止画面请求、清空输入并撤销未完成会话；创建响应迟到时仍撤销该会话，其他管理员会话不得接管。

## CSDN 发布设置

平台账号页维护默认发布预设，单篇平台稿可独立修改。单篇修改与标题和正文一起保存为新修订，再重新确认。已读取的 CSDN 专栏最多选择 3 个，摘要限 256 字符。平台稿预览提供服务端批准的原图链接，按需打开。保存草稿后，发布设置保留在已确认的平台稿供发布任务使用。转载或翻译的原文链接和授权确认由管理员按篇填写。

已核对的 CSDN 集成草稿在“平台任务”的任务详情中提供正式发布入口。管理员确认目标账号、文章、可见范围和冻结选项后，后台创建独立的发布任务。处理状态在该任务中查看，待核对状态提供只读核对。

## 小红书账号工作台

沿用后台蓝灰配色、系统中文字体、账号摘要和紧凑列表。原生账号选择框支持键盘操作；按账号重新挂载视图，切换后清空筛选与旧列表。小红书只显示笔记及账号设置，没有素材、草稿、发布设置或远程登录入口。任务和处理记录显示真实平台。缺失指标用“—”，同步失败保留并标明旧快照。

| 调整前 | 调整后 | 原因 |
| --- | --- | --- |
| 固定 CSDN 工作台 | [账号选择与隔离视图](../apps/admin/src/PlatformAccount.tsx) | 同一后台管理两个平台，避免串号 |
| 文章模型与草稿操作 | [小红书笔记只读列表](../apps/admin/src/XiaohongshuAccount.tsx) | 仅展示本次开放能力 |
| 固定平台任务标签 | [按任务显示平台](../apps/admin/src/Jobs.tsx) | 明确检查与同步的账号归属 |
| 停用账号的旧链接 | [显示未配置选项并可切回 CSDN](../apps/admin/src/PlatformAccount.tsx) | 避免选项与页面账号不一致 |

合成账号端到端用例已检查 1440、390、320 视口、键盘选择、减少动态效果、搜索与分页。窄屏表格在内部横向滚动，页面不整体溢出；截图由[多平台用例](../tests/e2e/platform-accounts.spec.ts)生成并由 CI 保存，不包含真实账号。
