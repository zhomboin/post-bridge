# 小红书接入方案

## 目标与当前状态

接入单个小红书账号的图文笔记立即发布，沿用 Go API、PostgreSQL 队列和 Node.js/Playwright 固定执行器。管理员确认独立平台稿后，由服务器上传素材、填写并提交，记录笔记标识、平台状态和核对时间。运行不依赖 AI Agent 或模型密钥。

方案依据[需求](requirements.md)、[总体计划](implementation-plan.md)与[平台能力](platform-capabilities.md)。具体步骤见[小红书实施计划](plans/xiaohongshu-integration.md)。接入尚未实现；本轮授权仅限匿名页面与环境验证，不登录账号，不上传、保存远端草稿、发布或删除内容。

## 路线与参考实现

资料核查日期：2026-11-08。官方账号授权文档仅将基本信息列为已开放，读取与发布笔记仍列为规划中，同时提供敏感权限申请说明。未取得目标应用的有效发布权限前，不能把账号授权当作发布授权。取得适用的官方接口权限后优先采用官方接口。

小程序能力介绍描述将内容和媒体带入客户端发布器，由用户完成发布。本次未完整读取具体组件文档，资格与限制继续待核实；目前不将其作为服务器持续执行的依据。

本项目使用标准 Playwright，不引入设备指纹伪装、验证码绕过、代理轮换或自动化特征隐藏。页面结构不符时停止并报告。

## 交付边界与内容

首个交付范围为单账号、图文笔记和立即发布；不增加视频、定时、批量搬运、互动操作、自动改写、自动配图、自动更新或删除。

小红书平台稿单独保存标题、纯文本正文、话题、封面选择和有序配图，不改写来源原稿，不自动截断技术长文。正文不适配时在确认前要求编辑。图片先由用户提供；长文转图片不属于本次范围。

开源实现中的标题 20 字、正文 1000 字仅作待验起点。实际字符计数、话题计数、图片数量、格式、体积、尺寸、上传顺序和封面方式均由目标账号验证后提供能力约束，在预览、确认和执行前共同校验。

PostBridge 平台稿、页面填充和小红书远端草稿分别记录；未验证远端草稿跨会话持久化前，不开放对应保存能力。正式发布仍是交付目标，不能以仅填稿替代。

## 现有系统的接入改动

| 范围 | 当前实现定位 | 接入要求 |
| --- | --- | --- |
| 账号 | [账号表](../apps/api/schema.sql)、[任务模型](../apps/api/model.go) | 移除固定账号限制，增加平台归属；迁移保留 CSDN 账号、任务和记录 |
| 调度 | [执行循环](../apps/worker/src/worker.ts)、[入口](../apps/worker/src/main.ts) | 领取权限、心跳、账号锁、登录与核对按平台账号绑定，禁止跨账号执行 |
| 登录 | [配置](../apps/worker/src/config.ts)、[登录浏览器](../apps/worker/src/login-browser.ts) | 平台白名单与身份校验独立；账号使用不同私有浏览器目录，等待验证释放执行槽位 |
| 平台稿 | [来源内容模型与校验](../apps/api/integration_content.go) | 增加图文稿与平台选项；正文、话题、图片校验值、顺序、封面和目标操作参与不可变修订与确认 |
| 素材 | [CSDN 图片入口](../apps/api/csdn_images.go) | 建立独立素材接收与受控下载；不复用 CSDN 图片地址充当小红书素材 |
| 页面与契约 | [平台账号](../apps/admin/src/PlatformAccount.tsx)、[外部契约](../contracts/cms.openapi.yaml) | 展示真实平台能力；未通过关口的操作拒绝；外部发布具有独立权限与确认 |

API 负责素材来源、实际内容、地址解析、跳转、大小和时限检查，并冻结校验值。worker 仅读取所属任务的已批准素材，通过平台官方页面上传。来源变更、取消和到期清理不能删除仍被有效任务使用的素材。

## 提交与结果核对

确认绑定平台、账号、操作、平台稿修订和素材；填写后再次核对。发出可能创建内容的请求前持久化对应检查点，记录上传副作用与正式提交边界，不将上传完成视为发布。

正式提交仅发出一次。收到平台接受证据后提取笔记标识，进入创作记录只读核对标题、正文、图片、账号、可见范围和状态；平台标识与真实链接绑定，不从任意页面文本猜测。平台转换后的正文和图片须通过实测确定可核对字段，不能假定远端保留原始文件校验值。

分别展示已受理、审核中、驳回、已公开和未知；无法确认公开阅读时不能显示已公开。提交超时、响应丢失、取消、失租和重启先核对，不能进入普通自动重发。没有唯一笔记身份或核对证据时交管理员处理，保留未知状态。

## 验证与进入条件

按匿名环境、授权账号只读、授权素材与草稿、授权单篇公开提交、生产五层推进。每层记录实际证据与未验项，前一层不能替代后一层；详细清单见[实施计划](plans/xiaohongshu-integration.md)。

敏感配置、原始响应、账号身份和验证地址仅保存到获准的本地私有配置目录，文档使用占位符；不采集登录与验证码页面。匿名验证使用全新会话，不加载既有账号目录。每轮结束关闭本轮页面、浏览器、CLI 与辅助进程，核对无残留，不停止无关服务。

当前只允许匿名页面与环境验证。真实账号、上传素材、远端草稿、公开提交和删除需分别明确账号、样例与操作范围，未满足前保持待验。完成文档与模拟测试不代表 A04、C06 或三平台首期通过。
