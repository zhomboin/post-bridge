| 真实平台 | 指定 CSDN 账号的登录、后台文字草稿、文章只读、单图转存及单篇官方表单提交已有证据。指定小红书账号的登录、资料统计和空笔记列表只读已验 |

## CSDN 草稿、只读与发布

| 检查 | 证据与边界 |
| --- | --- |
| 正式后台文字草稿 | 实际 Node 执行器经官方编辑器保存；重新读取标题、正文及草稿状态与冻结稿一致。相同请求返回同一任务。只读核对原任务不创建或改写草稿 |
| 正文图片 | 单张获准公开 JPEG 经 CSDN 转存并保存草稿。关闭重开后图片可解码，正文与保存请求匹配。目标域、地址、数量与副本校验具备合成回归。封面、多图及平台尺寸和格式上限继续待验 |
| 账号只读 | 完整同步已发布、草稿、未通过、回收站列表及七日趋势。已发布样例的 Markdown、HTML 和标签通过隔离 API 保存并读回。失败保留旧数据及筛选分页恢复有合成测试 |
| 指定草稿到发布验收 | 2026-11-04，一篇用户指定的既有草稿经官方表单公开提交一次。同一稿件读回已发布，标题和正文一致，用户以无痕窗口确认正文可读。自动化公开页访问受 WAF 403 限制 |
| PostBridge 自动正式发布 | 独立确认接口、冻结发布设置、提交检查点、原稿只读核对及防重复具备 PostgreSQL 与模拟平台回归。对应真实账号端到端、审核拒绝和自动化公开页待验 |
| 自动恢复 | 合成覆盖候选冲突、两次完整空查询、安全重试预算、取消与失租。真实账号管理页已有一次只读空匹配证据；真实自动重新保存和正式提交超时仍须专项核对 |

真实文章标识、原始正文、链接、响应及账号凭据仅在私有验证记录中保留。平台能力和待验清单见[统一平台验证清单](platform-capabilities.md#统一平台验证清单)。
