## 后续证据登记字段

| 字段 | 要求 |
| --- | --- |
| 记录编号与关联要求 | 关联阶段任务及需求验收项 |
| 验证层次 | 明确代码、本地验证、平台实测或生产验收 |
| 时间与人员 | 记录时区、执行及审阅人员 |
| 环境与版本 | 记录执行环境、浏览器、工具及对应提交 |
| 平台与账号 | 使用脱敏标识，与账号授权范围对应 |
| 授权依据 | 分别记录登录、公开测试、清理的权限及范围 |
| 输入与预期 | 使用无敏感内容的样例标识，说明正常、边界或异常场景 |
| 实际结果 | 区分未提交、接受提交、审核中、已公开、拒绝或未知 |
| 外站证据 | 记录可获得的文章标识、允许展示的链接、来源及最后确认时间；缺失时明确说明 |
| 证据引用 | 仓库仅保存脱敏摘要；敏感原始证据保存在仓库外受限位置，只登记受控引用 |
| 清理结果 | 记录授权内容、浏览器、临时目录、服务与执行锁的回收结果 |
| 结论与待办 | 标明通过、未通过或待验，以及影响、责任和复验条件 |

满足对应通过条件后才更新任务和阶段状态。无法读取审核结果时保持未知，不以环境初检或模拟结果推定真实平台验收通过。
