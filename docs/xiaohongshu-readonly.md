# 小红书账号与笔记只读工作台

## 账号资料与统计

在“平台账号”选择小红书，点击“同步笔记”。同步会先核对小红书号及稳定用户标识，再读取官方首页的头像、昵称、简介、关注、粉丝和获赞与收藏，以及近七日统计和笔记列表。未返回的数据显示“—”，不能用零代替。

“数据统计”显示平台返回的固定七日区间，包括发布笔记、阅读、曝光、点赞、评论、收藏、分享与净增粉丝，以及六项趋势。关注、粉丝和获赞与收藏是账号资料，七日指标不冒充累计指标；净增粉丝可以为负。日期按北京时间整理，统计区间随平台数据更新。

## 笔记列表与详情

笔记列表显示封面、图文或视频类型、标题、发布时间、发布状态及互动数据，支持搜索、筛选和分页。平台未识别的状态保留为“状态待确认”。“平台查看”打开小红书官方笔记地址，实际可访问性由平台决定。

点击标题进入独立详情页。首次打开已发布笔记且没有正文或读取任务时，只发起一次只读读取；失败后不会自动循环请求，可手动重新读取。执行器从当前账号的官方笔记列表点击封面查看入口，核对笔记和作者标识后保存正文、话题与图片。审核中、未通过、非公开或官方页面不可读的笔记不能通过编辑器绕过读取限制。

正文按纯文本展示，不执行 HTML。头像、封面和正文图片只接受受限的小红书图片域名，图片加载不发送来源信息。详情返回列表时保留账号与筛选；切换账号清除另一账号的数据。

## 保留与隔离

同步只有完整分页及身份核验通过后才替换快照；失败、取消、失租和结构变化保留已有结果。正文读取独立排队，同一账号同一笔记的活跃请求合并。读取失败保留已缓存正文，旧连接不能回写结果。

账号资料、统计和列表存于账号的笔记快照；正文按账号、笔记分别保存。数据库行权限、账号归属、连接版本及内部执行凭据继续生效。运行会话和备份放在仓库外，沿用[开发说明](development.md)与[部署说明](ubuntu-deployment.md)的备份和升级步骤；本功能不增加必填配置。
