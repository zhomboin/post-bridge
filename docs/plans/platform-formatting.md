## F2：契约和确定性转换

- [x] F22 核对现有格式化任务、结果、数据库、来源契约及类型生成路径，确定新增字段及兼容方向；见[改造依赖](platform-formatting-observations.md#改造依赖)，具体字段约束与兼容实现继续由 F23—F40 完成。
- [x] F23 公众号支持保真排版和 AI 辅助建议，CSDN 与小红书沿用 AI 格式化。能力接口列出可用模式，服务端拒绝未知模式、未启用组合及跨模式请求。
- [x] F24 已定义有序内容块、公众号富文本、本地素材映射、问题、候选稿及版本字段，素材最多 20 张、合计 4 MiB，随会话到期。
- [x] F25 新字段按需随 JSON 保存。隔离数据库重新初始化、缺少新字段的旧记录读取、原请求重放及并发确认通过；编辑新修订保持原确认和内容冻结。
- [x] F26 独立转换核心接入任务和隔离预览，覆盖段落、标题、列表、引用及表格并记录原块。真实公众号效果由 F54 验收。
- [x] F27 保留四段合成代码的原文、空格和语言，并保留样稿安全链接目标。代码图片取决于 F54 的真实编辑器结果。
- [x] F28 表格和常见 HTML 转换通过；不支持的行内 HTML、公式和未知扩展保留可核对原文，并在后台定位对应段落。
- [x] F29 Markdown、引用及 HTML 图片按来源顺序和位置映射，用户可选择本地 PNG／JPEG；未提供或未能映射时保留提示，不自动访问外部地址或推断已上传。
- [x] F30 预览与复制共用独立白名单净化，保留可读内容及当前修订绑定的本地图片；预览使用隔离框架和内容安全策略。合成浏览器用例确认危险内容不执行、外站图片不加载。
- [x] F31 已接入认证的独立验证入口，按原稿块核对文字、代码、安全链接及图片占位；差异保留候选稿并提示核对，无法完整自动核对的内容明确提示。转换与验证限制请求和响应大小，计算在线程中执行，30 秒超时或取消时终止线程，并限制并发；接口及线程测试通过。
- [x] F32 转换、认证、输入边界、任务集成和 13 份样稿的来源映射及独立保真校验通过。未知标签及行内 HTML 显示人工核对提示。

## F3：任务、授权和修订

- [x] F33 本地公众号任务不要求模型密钥、不请求模型、不预留或消耗模型额度；独立数据库和实际 formatter 的合成链路通过。
- [x] F34 公众号本地原稿逐篇授权后使用 AI 辅助，共用模型用量与超时限制；外部来源的应用和单篇授权继续生效，公众号未开放给外部来源。
- [x] F35 新修订绑定平台、模式、规则和提示词版本、模型及素材摘要，旧 JSON 仍可读取。
- [x] F36 公众号确认绑定平台、修订、规则、内容和素材摘要；编辑及素材变化产生新修订、取消旧确认，旧修订保持冻结。
- [x] F37 公众号转换和独立校验进行中取消会中止请求并保留取消状态；校验中会话过期不会生成可用结果。用隔离 PostgreSQL 和实际 formatter 分别验证完整 API 在转换、独立校验请求中强制退出。重启后保留有效租约和排队状态；模拟租约到期后，中断任务标记为失败，无候选修订或自动重试，排队任务正常完成。旧执行器无法覆盖恢复状态。来源 CSDN 格式化执行前撤销授权、停用平台账号或用户时不调用模型；模型请求期间失效不会保存或采用结果；候选稿生成后来源或账号失效时不可读取、采用，列表不显示原题。相关 Go race 用例通过，见[验收记录](../acceptance.md#ai-格式化)。
- [x] F38 公众号素材跨用户隔离、到期拒绝访问和保真模式零模型额度通过。检查了素材数量和持久结果大小约束、固定错误码、异常响应脱敏及私有配置传递。
- [x] F39 已更新共享契约与各端生成类型并通过一致性检查；公众号仅支持本站本地原稿，未扩展外部来源写入目标。
- [x] F40 公众号请求、素材、旧数据、权限、并发编辑与确认、取消、会话过期和进程重启，以及 CSDN 与小红书相关定向回归通过。

F3 通过：权限、修订和已有 CSDN／小红书功能回归通过；无模型与 AI 路径的状态和用量清楚。
