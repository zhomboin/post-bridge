# E：上线与运维实施计划

> 执行人员使用 executing-plans 按任务推进，独立审阅使用 subagent-driven-development。依据[总计划](../implementation-plan.md)、[需求](../requirements.md)和[后台规范](../admin-ui.md)。E01 的环境结构在 B 已可运行，本阶段执行生产加固与验收，生产变更和真实账号操作须在明确授权范围内。

## E01：独立生产部署与访问边界

前置：B01、B03、B08，正式切换等待 C、D 通过。

拟建：`deploy/compose.production.yaml`、`deploy/proxy/nginx.conf`、三个应用的 `Dockerfile`、`deploy/browser/Dockerfile`、`scripts/deploy.ps1`、`docs/deployment.md`、`docs/security.md`。

- [ ] 测试首次空环境启动、数据库未就绪、密钥缺失、迁移失败、内部服务不可达和配置超限，部署失败不得留下半可用入口。
- [ ] 固定镜像版本与依赖，设置独立网络、数据库权限、持久化目录、非特权运行及资源限制；CMS 不共享内部容器地址和凭据。
- [ ] 前端与 API 由同站点加密入口提供，配置会话、代理与安全响应策略；数据库、执行器、调试及远程桌面原始端口只在内部网络开放。
- [ ] 对管理接口、截图、素材及远程连接逐项验证匿名拒绝和过期失效，确认代理不能绕过 API 鉴权。
- [ ] 验证服务器正常启动、页面可访问、后台登录、健康检查及停止清理，记录拆迁服务器时需要迁移的资源。

测试定位：`tests/integration/deployment.test.ts`、`tests/e2e/access-control.spec.ts`。通过：独立启动不依赖 CMS 内部服务，公网仅暴露受控必要入口。

## E02：有限参数、监测与保留清理

前置：B09、E01。拟维护：`apps/api/internal/settings/`、`deploy/`；拟建：`docs/operations.md`、`tests/integration/retention.test.ts`。

- [ ] 按总计划参数表逐项测试边界、非法值、负数和无限值；在目标环境确认有效默认值及上限并写入运维文档。
- [ ] 测量浏览器并发、CPU、内存、磁盘、数据库与素材峰值，以结果调整容量，不能把起始并发当作生产承诺。
- [ ] 触发积压、持续失败、等待验证、执行器离线和磁盘告警，后台可定位任务与日志；首期不强制外部通知渠道。
- [ ] 验证素材、快照、日志和失败诊断到期清理，活跃任务被引用的数据不误删；禁止采集登录和验证码页面。
- [ ] 验证磁盘保护可暂停新任务并提示管理员，恢复后安全继续；不得为腾空间自动删除有效会话。

通过：所有运行参数有限且可追溯，后台真实反映故障和资源风险，过期数据能按策略清理。

## E03：备份恢复、密钥轮换与升级回退

前置：E01、E02、D03。拟建：`scripts/backup.ps1`、`scripts/restore.ps1`、`scripts/upgrade.ps1`、`tests/integration/restore.test.ts`；维护运维及安全文档。

- [ ] 列出数据库、必要浏览器会话文件、加密密钥及配置的独立受限备份方式；备份不进入仓库或普通日志。
- [ ] 在隔离环境恢复备份并验证来源、账号、任务与外站关联；密钥缺失或会话过期明确提示，不能将仅恢复数据库判定为全部恢复。
- [ ] 演练管理员、来源和执行器凭据以及加密密钥轮换，验证旧凭据撤销、连接恢复和审计，不暴露明文秘密。
- [ ] 升级前停止新领取、保存状态、释放浏览器和锁并备份；验证迁移失败后的恢复或回退路径，而非假设所有迁移可逆。
- [ ] 在排队、执行中、等待验证、提交不确定等阶段分别重启，核对中断提交后恢复；进程清理不影响其他项目服务。

通过：备份确实可恢复，升级中断和回退有证据，提交不确定任务不会自动重新发文。

- [ ] 覆盖来源与管理员越权、请求重放、跨站写请求、正文和日志脚本注入、素材地址与重定向、远程会话过期及秘密泄露。

通过：所有必要要求有证据，平台限制与剩余风险清晰，不能因演示页面正常而宣布上线验收完成。
