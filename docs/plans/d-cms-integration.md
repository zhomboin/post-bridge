# D：CMS 对接实施计划

依据[总体方案](../cms-integration.md)、[外部接入手册](../external-integration.md)和[总计划](../implementation-plan.md)。PostBridge 侧 CSDN 文字 Markdown 保存草稿来源接入已实现并本地验证；CMS 项目未改，双方契约审阅、实际连接与联合验收仍未完成。保留未完成计划，不将单侧子范围作为整阶段通过。

## D01：契约与共同样例

PostBridge 侧文件为 [OpenAPI](../../contracts/cms.openapi.yaml)、[共享签名与指纹向量](../../tests/fixtures/integration-contract.json)及[共享契约用例](../../apps/api/integration_contract_test.go)。

- [x] 明确 CMS 主入口、PostBridge 预览与异常入口，以及双方独立身份和数据职责。
- [x] 形成实际外部与管理员确认接口、签名固定 profile、指纹、错误与限制的机器契约和手册。
- [x] 后台文档图标打开站内接入手册，支持章节目录、窄屏表格及契约、测试向量下载；与现行 Markdown 同源。
- [x] 固定当前目标为 CSDN 文字 Markdown save_draft，未实现的公开发布、图片、MDX 和其他平台明确拒绝。
- [x] PostBridge 本地校验共享签名与指纹向量、路由覆盖、模型和来源严格状态响应。
- [ ] CMS 结合自身实现审阅并共同确认契约与测试向量。
- [ ] 双方登记私有联调配置，完成各自身份、反向注册和来源服务连接；不提交真实账号、地址或凭据。
- [ ] 补充公开发布和素材契约，并在能力实现后完成双方审阅；不以当前草稿子范围勾选。

通过条件：双方实现、共同审阅和实际联调都有证据。D01 的 PostBridge 定义已交付，整体仍未完成。

## D02：CMS 发布选择与可靠投递

前置：D01 双方审阅；PostBridge 受限接口已可供调用方独立实现。CMS 页面、文章事务、迁移、连接器和发送器在 CMS 仓库通过独立 PR 实施。

- [ ] 第三方目标默认不选，保留只发自有博客；用户主动请求后才发送授权快照。
- [ ] 跳转 PostBridge 预览确认，CMS 后端重新读取确认结果，不信任浏览器回参。
- [ ] 同一事务核对原稿、保存站内发布及待发送；正文变化重新预览，纯状态版本变化按指纹核对。
- [ ] 事务成功后投递，保持稳定请求标识；丢响应先查询或同标识重投，断网和重启不丢意图。
- [ ] 未确认、过期及撤销保持待处理，自有博客可独立发布。
- [ ] CMS 后端轮询父分发摘要与详情，离开、隐藏和退出停止刷新，失败有界退避。
- [ ] 已有副作用、未知结果或活跃任务显示重复限制，不用新标识绕过；确定未写入旧任务的安全替代需新授权与新预览确认，已有外站副本的显式再次新建仍属后续能力。

通过条件：CMS PR 的事务、断网恢复、去重和页面关闭均有模拟及联合证据。当前未实施。

## D03：生命周期与外站写入前复查

PostBridge 实际实现位于 [integration_content_store.go](../../apps/api/integration_content_store.go)、[integration_source.go](../../apps/api/integration_source.go)、[integration_guard.go](../../apps/api/integration_guard.go)；测试定位为 [integration_content_test.go](../../apps/api/integration_content_test.go)、[integration_source_test.go](../../apps/api/integration_source_test.go)、[integration_guard_test.go](../../apps/api/integration_guard_test.go)。

- [x] PostBridge 事务接收来源事件，拒绝同标识不同内容和同序列不同实际状态；旧状态不回退。
- [x] 单独记录授权撤销，指定授权不可复用，不误撤同文章其他授权；私有、下架、删除作用整篇。
- [x] 实现反向来源实时检查与受限 HTTPS 出站；CSDN 草稿关键写入阶段不可确认时停止新写入。
- [x] 内容或授权变化清理无用未提交稿件，保留进行中与未知结果所需数据；已发生外站操作保持核对。
- [x] 来源暂停与平台登录分别处理；恢复重新核验来源、授权、原确认和有效租约，沿用原任务。
- [ ] CMS 在业务事务中保存事件、授权状态与发件箱，实现权威状态服务并验证可靠补发。
- [ ] 双方覆盖通知与实时检查交错、授权到期、删除后查询和跨网络不可达；联合证据仍待。
- [ ] 图片启用后实现原稿绑定素材授权、下载上传及清理；当前文字子范围拒绝素材。
- [ ] 公开提交能力完成后验证最终提交边界；当前来源守卫不等于自动公开发布已交付。

通过条件：双方生命周期与实际写入边界共同通过。PostBridge 草稿守卫已验证，D03 整体仍未完成。

## D04：分层联合验收

完整 D04 依赖 D02、D03 和 C07；CSDN 文字草稿只能作为子范围，不关闭三平台首期。

- [ ] 双方模拟站内发布后断网、丢响应、重启、重复请求、部分成功和关闭 CMS 页面。
- [ ] 联合验证纯状态版本变化、正文变化、跨页编辑、未发布、未预览、过期及撤销授权。
- [ ] 联合验证注册审批与激活、反向身份、权限缩减、跨实例防重放、轮换和认证设施不可用。
- [ ] 不同网络经 HTTPS 验证代理目标、时钟、受限出站、来源状态和执行前守卫。
- [ ] 完成授权 CMS → PostBridge → CSDN 文字草稿联合链路，只记录草稿保存。
- [ ] 待公开发布及其他平台能力具备后，逐平台验证提交、审核和公开阅读。
- [ ] C07 后完成三平台完整验收及常驻服务器用户离线后继续执行。
- [ ] 两仓库分别完成 PR 审阅、文档同步及临时资源清理，生产与本地结果分别登记。

当前只有 PostBridge 单侧代码与本地子范围通过，完整 D04 未通过。实际证据进入[验收记录](../acceptance.md)和[总体进度](../progress.md)。
