# D：外部系统接入与联合验收

依据[总体方案](../cms-integration.md)、[外部手册](../external-integration.md)和[总计划](../implementation-plan.md)。标准接口面向任何获批调用方，不要求 CMS 常驻或反向服务；本地代码、真实调用方、真实平台与生产分别验收。

## D01：固定契约与共同样例

- [x] 提供固定注册、HMAC 签名、权限、准备稿、人工确认、分发查询及主动取消契约。
- [x] 当前目标仅为 CSDN 文字 Markdown save_draft，明确拒绝未实现能力。
- [x] 共享签名／指纹向量与站内同源手册可供调用方独立实现；新增调用方只需配置授权。
- [ ] 与真实调用方共同核对协议、向量、确认流程及稳定业务标识。
- [ ] 公开发布与素材能力实现后补充对应契约及共同审阅。

实现：[OpenAPI](../../contracts/cms.openapi.yaml)、[共享向量](../../tests/fixtures/integration-contract.json)、[契约用例](../../apps/api/integration_contract_test.go)。PostBridge 标准定义可用，真实调用方联调关口仍待。

## D02：调用方选择与可靠投递

CMS 的具体数据、接口、页面及 C1—C7 实施关口见[CMS 侧接入方案与改造计划](cms-client-integration.md)。该专项为待实施方案，不以文档完成关闭真实调用方验收。

- [ ] 调用方后端按实际能力发送明确授权快照，不泄露私有字段或业务浏览器密钥。
- [ ] 跳转 PostBridge 人工预览确认，后端重新读取确认结果并原样透传，不信任浏览器回参。
- [ ] 使用稳定 request_id，响应丢失先查原结果，断网或重启后有界恢复发送。
- [ ] 展示父分发摘要，区分已接收、执行完成、平台草稿与未知结果。
- [ ] 验证源内容、序列或授权改变时重新准备与确认，不能绕过已有副作用和活跃任务限制。
- [ ] CMS 适配如需站内发布与投递一致，可采用事务发件箱；实现方式由 CMS 自行决定，不作为服务准入条件。

调用方代码在其独立项目实施，不要求新增 PostBridge 定制分支或反向路由。当前真实调用方未验收。

## D03：本地授权与主动失效

- [x] 提交、领取、关键写入与恢复检查本地快照授权、应用状态、目标权限和已收到来源状态。
- [x] 来源事件可主动通知内容变化与指定授权撤销，幂等和乱序不会回退已知状态；无事件也可准备、确认和提交。
- [x] 签名取消仅作用自身分发并停止后续执行，正文按现行保留条件清理；存在或可能存在外站副作用时拒绝取消并继续核对。
- [x] 来源暂停与平台登录分开；恢复需原确认和当前有效授权，未知结果不得普通重试。
- [ ] 真实调用方验证授权期限、状态变化、撤销与执行交错，以及重要失效通知可靠发送。
- [ ] 素材与公开发布能力交付后扩展对应边界，不用当前文字草稿代替。

实现：[integration_content_store.go](../../apps/api/integration_content_store.go)、[integration_guard.go](../../apps/api/integration_guard.go)。PostBridge 不主动读取调用方当前状态，调用方须主动报告需要停止的变化。

## D04：分层联合验收

- [ ] 真实调用方验证邀请审批、激活、权限收紧、防重放、轮换、暂停与撤销。
- [ ] 真实调用方验证无反向服务、无需先发事件的完整准备、人工确认、提交、轮询与取消。
- [ ] 真实调用方验证丢响应、断网、重启、重复请求、过期、失租及未知外站结果。
- [ ] 经 HTTPS 完成真实调用方 → PostBridge → CSDN 文字草稿链路。
- [ ] 完成跨网络常驻、备份恢复、时钟和生产验收。
- [ ] 公开发布及其他平台具备后，逐平台验证真实提交、审核与公开阅读；C07 后完成完整首期。

当前标准接口本地验证不关闭真实调用方和生产验收。证据统一进入[验收记录](../acceptance.md)和[总体进度](../progress.md)。
