# 小红书接入实施计划

## 范围与状态

依据[接入方案](../xiaohongshu-integration.md)、[需求](../requirements.md)、[A 阶段](a-platform-validation.md)和[C 阶段](c-platform-publishing.md)。先验证平台能力，再完成账号拆分、独立图文稿、素材和发布核对。完整目标为单账号图文笔记立即发布；当前交付为多平台账号、小红书登录检查与笔记只读列表，图文稿、素材和写入尚未实现。

X01、X02 登录及只读空列表与图文上传前检查已完成。用户授权笔记列表与编辑器只读访问，禁止上传素材、保存草稿或公开发布；未填写图文内容或删除笔记。当前列表无非空样本，上传后的编辑字段不可见，X02 整体未通过。账号标识和原始数据仅存本地私有目录，结果见[平台能力](../platform-capabilities.md)、[验收记录](../acceptance.md)和[进度](../progress.md)。

- [x] 完成官方资料、开源源码和当前仓库限制核查，形成接入方案与实施顺序。
- [x] 明确 X01 仅做匿名检查，真实账号与外站写入分别授权。
- [x] 检查目标环境 Node、Playwright、浏览器与中文显示条件，记录实际版本，不把缓存标识当浏览器版本。
- [x] 用全新匿名浏览器打开官方创作入口与发布入口，记录实际页面、重定向、登录门槛和不可访问原因。
- [x] 区分网络响应、页面渲染与账号能力；登录门槛后的图文限制保持待验。
- [x] 关闭本次临时资源，核对进程无残留；完成文档链接、编码、隐私和差异检查。

通过：匿名访问与环境结果有证据，失败也明确记录原因；不要求取得账号发布结论。此项不能关闭 A04。

X01 证据：项目 Playwright 1.64.1 可启动启用沙箱的 Chrome 156.0.8078.4；匿名入口进入短信登录页，未见上传控件。已登录账号及上传前限制的当前证据见 X02 和[验收记录](../acceptance.md)。

## X02：授权账号与只读能力

前置：按子范围明确目标账号及官方登录、会话重启、已有笔记只读授权；不以登录授权替代内容操作授权。

- [x] 明确目标账号及登录、身份、重启、笔记列表与图文编辑器只读授权；素材上传、草稿和公开发布禁止。
- [x] 在专用私有目录完成官方交互登录，核对小红书号与预期身份；不粘贴 Cookie，不记录验证码或扫码秘密。
- [x] 关闭并重启后检查会话；官方稳定用户标识与小红书号均保持一致。
- [ ] 验证登录失效、短信或验证要求的识别与退出。
- [x] 验证笔记管理全部、已发布、审核中与未通过的空列表和原生只读请求；搜索匹配及分页因缺非空样本继续待验。
- [x] 只读检查图文上传前的格式、多选、大小与尺寸提示；仅记录页面提示，不以此替代实际素材验证。
- [ ] 验证发布资格、上传后的标题、正文、话题、封面和实际字符与素材限制。
- [ ] 验证非空笔记及详情的稳定标识、正文、配图、可见范围、审核状态与真实链接。
- [x] 拦截发布页初始化的上传探测与许可请求，确认未放行内容写入；填稿后的自动保存行为继续待验。

通过：A04 的账号、内容和只读部分有证据；不能核对的字段明确记录。没有唯一结果识别方式时，保留公开发布阻塞。

当前登录、空列表及图文上传前子范围通过，X02 整体未通过。私有会话保留，浏览器、辅助进程及会话锁无残留。正常登录放行原生认证与安全校验，内容写入仍受限；本地验证助手仅临时使用，不提交到仓库。

## X03：多平台账号与调度基础

前置：X02 形成可执行浏览器路径；不依赖外站写入的模拟工作可以先推进。

- [x] 修改[账号与任务](../../apps/api/schema.sql)，支持平台归属并迁移现有数据，不改变 CSDN 身份与任务关联。
- [x] 修改[worker 协议](../../apps/worker/src/types.ts)与[领取执行](../../apps/worker/src/worker.ts)，绑定平台账号、能力和凭据；错平台、错账号与过期领取均拒绝。
- [x] 按平台拆分[账号配置](../../apps/worker/src/accounts-config.ts)与适配器选择，保持账号互斥和私有浏览器隔离；CSDN 保留远程登录，小红书仅复用会话进行登录检查。
- [x] 通过定向数据库与执行器回归验证双平台隔离、登录等待、取消、失租、重启及旧 CSDN 任务兼容；真实非空账号的异常恢复仍待验。

当前只读范围通过：双平台独立领取，停用账号拒绝新建或恢复任务，旧数据保留；未开放小红书写入能力。

## X04：独立图文稿与素材

前置：X02 的字段和素材规则明确，X03 账号归属可用。

- [ ] 扩展[来源内容](../../apps/api/integration_content.go)，独立保存标题、纯文本、话题、有序图片和封面；所有实际分发字段参与确认，不静默截断或删减。
- [ ] 建立受控素材接收、下载与临时访问，校验地址、跳转、实际文件、数量、大小、权限和校验值；worker 仅接收批准素材。
- [ ] 为图文预览与编辑增加边界校验；前端实施前共同读取项目内两个设计技能，检查桌面、390/320、键盘和减少动态效果。
- [ ] 更新[机器契约](../../contracts/cms.openapi.yaml)及签名与指纹向量，验证旧来源协议兼容；未开放操作由服务端拒绝。
- [ ] 覆盖缺图、错序、重复素材、伪造类型、私有地址、超时、失效、修订竞争、取消和素材清理。

通过：预览、确认和执行使用同一内容与素材版本，模拟验证通过。

## X05：上传、填写与远端草稿验证

前置：X04；真实上传与远端草稿操作有指定账号、合成样例及单独授权。

- [ ] 依据 X02 证据在[现有执行器](../../apps/worker/src)内实现固定小红书适配，优先稳定语义定位；结构不符停止。
- [ ] 上传前记录可能的外站副作用，核对每张图片完成状态、顺序和封面；未完成不进入提交。
- [ ] 填写标题、正文与话题后读回核对；验证平台转换、字符计数、必填项和验证弹窗。
- [ ] 分别验证仅填页面与远端保存；若存在远端草稿，核对标识、重启持久化及只读恢复；不具备则明确不开放该能力。
- [ ] 覆盖上传中断、部分成功、登录失效、取消、失租与清理；不以填稿完成标记发布成功。

通过：授权范围内的图文准备有真实证据，正式提交仍需 X06。

## X06：一次提交与只读恢复

前置：X02 结果识别可行、X03—X05 通过，且指定单篇公开样例与可见范围已明确授权。

- [ ] 实现提交前持久化检查点与来源授权复查，仅允许绑定快照的一次正式提交。
- [ ] 从本次提交证据取得笔记标识，读回核对账号、标题、正文、图片与选项；返回真实链接和确认时间。
- [ ] 分别记录平台受理、审核中、驳回、已公开和未知；公开页受限时保留未验边界。
- [ ] 模拟响应丢失、平台接受后崩溃、取消、失租、重启与重复上报；不确定时只读核对，不再次点击发布。
- [ ] 缺少唯一笔记身份或证据不足时进入管理员核对；人工处置需依据与审计。
- [ ] 按明确授权决定保留或删除测试内容，核对浏览器与辅助进程全部退出。

通过：目标账号真实图文发布、内容核对及关键恢复均成立，才能记录 A04/C06 对应通过项。
