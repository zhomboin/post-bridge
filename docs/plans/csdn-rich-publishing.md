# CSDN 图文与发布预设实施计划

目标是让 CMS 已发布文章通过 PostBridge 发送图文稿，并在正式发布前使用账号预设、逐篇修改和确认。

## 相册图片验收

- [x] 已从公开相册选取 JPEG。匿名读取返回 200，链接无临时签名且响应含长期缓存。
- [x] 已验证 CSDN 转存同一张相册 JPEG 并保存草稿。重新打开后，草稿状态、正文与保存请求一致，转存图片已加载并解码。CMS 保留原图。验证完成后立即恢复执行器，未正式发布。
- [ ] 用模拟接口覆盖无图、重复图片、签名地址、私网地址、外部域名、重定向、无法解码和超时。可定位到具体图片的失败需要在确认前呈现。

## PostBridge 图文草稿

- [x] 在 `apps/api/integration_content.go`、`apps/api/model.go` 和对应测试中扩展受控 Markdown 图片校验。CMS 逐张核对正文和封面图片是否仍属于已发布相册的长期公开记录。PostBridge 核对明确配置的 HTTPS 图源，执行器在转存前检查公开 DNS，不直接下载源图。CSDN 自行连接图源并生成副本。执行器限制转存和副本预览的请求时间，拒绝重定向，保存前及草稿重开后检查副本可解码。原始 Markdown 进入现有快照和指纹，图片限于经验证的正文链接。
- [x] 在 `apps/worker/src/csdn.ts` 和执行器测试中按已批准图源开放必要的图片读取。通过 CSDN 官方外链转存获得副本，保存前核对仅替换批准的图片地址并确认副本可渲染，保存后重新读取草稿。只读恢复、账号互斥和提交防重复沿用现有流程。
- [x] 同步 `contracts/cms.openapi.yaml`、外部接入说明和目标能力。带图能力由服务端确认后开放，现有调用方仍能提交文字稿。

## 发布设置与确认

- [x] 按 CSDN 账号维护一套默认预设。在 `apps/admin/src/IntegrationDraft.tsx` 对应的稿件确认入口应用预设并允许单篇覆盖。单篇修改和更新预设是两项操作。
- [ ] 设置页使用 CMS 标签作为候选，缺失时使用预设。已实现摘要上限 256、专栏最多 3 个，专栏来自已读取的 CSDN 文章资料。标签必填、封面选择及选项写入 CSDN 原生发布表单由正式发布流程验收。文章类型、创作声明、可见范围和模板随修订冻结。GitCode 备份和多平台发布关闭。
- [ ] 正式发布使用独立操作和授权，默认流程及现有授权继续只支持保存草稿。单次确认绑定操作、目标账号、稿件修订和发布选项。执行前再次核对授权与来源状态，超时后通过原任务只读核对。分开记录草稿、提交受理、发布结果及未知状态。
- [ ] 用模拟平台验证预设保存与覆盖、改稿后原确认失效、草稿和正式发布的不同操作，以及超时恢复。覆盖权限不足、重复提交和来源撤销。真实发布须事先获得针对具体稿件、账号和可见范围的明确授权。

## CMS 联调与交付

- [x] CMS 在新分支读取 PostBridge 目标能力，允许已发布文章附带合规的公开图片。旧目标保留原有文字稿行为。
- [ ] 验证从 CMS 准备稿、PostBridge 修改和确认，到草稿回显的完整流程。分别记录模拟测试、真实平台和生产环境状态。
- [ ] 同步两边的接口和主进度，各自完成独立检视与 PR。
