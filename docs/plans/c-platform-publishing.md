# C 平台发布闭环

[总计划](../implementation-plan.md)定义阶段依赖，[平台能力](../platform-capabilities.md)记录真实证据。实际平台操作遵循已明确的授权范围。

## C01 内容转换与预览

CSDN Markdown 平台稿已支持独立预览、修订和确认。CSDN AI 整理、小红书本地图文及公众号本地转换见[格式化说明](../ai-formatting.md)。

- [ ] 补齐 MDX 及其他平台结构转换，覆盖代码、表格、链接、公式和图片。
- [ ] 核对各平台实际预览和冻结提交稿一致，明确不兼容内容及阻断条件。

## C02 素材

CSDN 正文图片由获准的公开图源提交给平台转存。地址、数量、解码与读回规则见[接入手册](../external-integration.md#csdn-正文图片)，定向用例见[API 图片测试](../../apps/api/csdn_images_test.go)与[执行器图片测试](../../apps/worker/tests/csdn-images.test.ts)。

- [ ] 验收 CSDN 多图、封面、格式、尺寸和数量边界。
- [ ] 按各平台实际能力实现并验证受控素材、上传及失败后的数据清理。

## C03 提交边界与恢复

CSDN 支持来源守卫、草稿保存、独立发布确认及提交后只读核对。实现见[发布任务](../../apps/api/csdn_publish.go)及[来源守卫](../../apps/api/integration_guard.go)。

- [ ] 在真实授权环境核对 CSDN 正式提交、失租、断线和响应丢失。
- [ ] 为其余平台提供身份复核、提交检查点、只读核对及审核状态映射。

## C04 CSDN

保存草稿与单张 JPEG 已有真实证据，独立发布在 PostgreSQL 和模拟平台通过。指定既有草稿的官方手工发布已有独立证据。详见[CSDN 计划](csdn-rich-publishing.md)。

- [ ] 在目标环境完成授权的 PostBridge 正式发布，确认原稿、可见范围、审核行为、自动化公开页与外站链接。

## C05 知乎

- [ ] A03 通过后，按实际账号能力完成登录、正文转换、素材、话题、提交、审核及真实发布恢复。

## C06 小红书

账号只读和本地图文生成已交付，图文写入步骤见[小红书专项计划](xiaohongshu-integration.md)。

- [ ] 验证非空真实笔记与分页，取得目标账号图文操作边界。
- [ ] A04 通过并获得对应授权后，实现并验证上传、远端草稿、一次提交和结果恢复。

## C07 三平台恢复验收

- [ ] 在模拟链路覆盖一平台失败、成功结果保留、取消、重启、失租、验证等待和浏览器回收。
- [ ] 分别验证三个平台在目标环境真实发布、提交不确定时先核对，以及退出后台后继续执行。
