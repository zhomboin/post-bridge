# 多平台格式对照记录

本记录用于专项实施，任务全部完成并确认后随[方案](../platform-formatting-design.md)和[计划](platform-formatting.md)一并删除。样稿为[独立合成数据](../../tests/fixtures/platform-formatting/samples.json)，图形由项目自行制作；图片地址仅为不可访问的占位符，真实采样时须使用获准素材，不把实际地址写入仓库。

## 现有能力与边界

AI 格式化要求单篇许可，来源稿还需要应用和单篇双重授权；模型任务预留用量并先分析再调用模型。公众号本地稿走独立的无模型任务，支持本地素材和候选稿修订；来源分发仍只有 CSDN 草稿。账号、素材和来源数据按用户隔离，确认绑定最终内容和规则，改稿需新修订。

私有原始采样应置于用户明确允许的本地私有配置目录，仅操作人员访问；本项目 `.local-tmp/` 已忽略，可用于不含凭据和真实账号的临时合成数据。实际目录、账号、凭据、平台原始响应及截图不记入仓库。证据在此只登记脱敏结论、样稿编号和采样阶段。

## 多类型离线预处理对照

对 13 份独立合成样稿，在隔离且禁止外部网络的浏览器中运行扩展的公众号与小红书图文预处理。输入 HTML 由合成 Markdown 独立生成；综合稿的小红书预处理正文与实测 AI 请求正文一致，其他样稿尚未与真实入口逐一核对，也没有对应 AI 结果或目标平台保存结果。

| 样稿及阶段 | 观察 | 项目处理原则 |
| --- | --- | --- |
| 结构、综合稿；小红书预处理 | 外链目标移除，表格转为文字 | 保留目标和单元格语义，不能保真时提示 |
| 图片稿；小红书预处理 | 两张输入图片均未进入预处理 Markdown | 按顺序记录素材及处理状态，不声称已上传 |
| 技术稿；小红书预处理 | 三段代码仅一段保留完全相同的代码内容 | 原文代码和空格必须保留，不能由模型重写 |
| 技术、结构、比较和图片稿；公众号预处理 | 分别可见代码块、表格和图片标签 | 仅说明中间 HTML 结构，不等于目标编辑器最终效果 |
| 结构、综合稿；公众号预处理 | 示例外链目标未保留 | 原文链接目标应可核对，缺失时提示 |

这些对照揭示的是扩展的局部处理，不能将其所有输出认定为正确，也不能将离线结果代替其他文章类型的 AI、公众号或小红书实际验收。

## 本地样稿对照

用 [13 份合成输入](../../tests/fixtures/platform-formatting/samples.json)运行当前 PostBridge 转换和独立校验。CSDN 一列使用已采集的同步助手离线预处理输出；真实短文和综合稿只核对过 CSDN 原稿保存，未取得公众号或小红书保存后的稿件。

| 样稿 | CSDN 同步助手中间结果 | PostBridge 本地结果与判定 |
| --- | --- | --- |
| 基础、长文 | 标题层级与输入一致 | 保持标题层级和段落顺序，独立核对通过 |
| 列表、教程、问答、短文 | 保留可见标题与正文结构 | 保留嵌套列表、步骤顺序、条件及问答顺序，独立核对通过 |
| 技术、综合 | 可见 4 个代码块；仅凭中间 HTML 不能判断目标编辑器显示 | 4 段代码原文与空格完整，长行在本地预览换行；代码粘贴效果待验 |
| 结构、比较、综合 | 三个表格均可见；结构与综合稿的 2 处外链目标未保留 | 三个表格均可见，保留原链接，公式保留原文并提示核对 |
| 图片 | 中间 HTML 有两张图片标签 | 两处按原文顺序保留素材占位，须关联本地图后确认 |
| 边界、长标题 | 仅采集正文预处理，无标题输入约束证据 | 未知扩展保留文字并提示，空标题和超过 100 字的标题由 API 拒绝 |
| 视觉 | 未采集目标编辑器和重开稿 | 本地预览、正文差异及建议的桌面和窄屏显示见[界面检视](../admin-ui.md#ai-格式化检视) |

13 份输出均通过独立保真校验。图片缺失、公式和未知扩展按稿件现状保留阻断提示。小红书同批离线结果仍只覆盖预处理，真实多稿 AI 输出与平台视觉对照沿用 F43–F46、F55。

## 处理范围

| 现有位置 | 当前约束 | 改造时需验证 |
| --- | --- | --- |
| 会话创建与来源守卫 | `formatting_source.go` 区分本地公众号与 AI 模式；来源仍检查应用许可和平台范围 | 后续扩展来源时不得放宽模型调用或跳过单篇授权 |
| 配置与调度 | `formatting_config.go` 支持本地转换独立启用，AI 模式另校验模型凭据 | 隔离数据库回归覆盖停用和恢复 |
| 创建任务和额度 | `formatting_store.go` 为公众号保真模式保留零模型额度，AI 辅助共用配额 | 验证了并发、取消、用量及重试 |
| 存储和确认 | 会话、任务及修订以 JSON 记录，确认基于最终结果 | 兼容旧 JSON，保证历史确认不被新默认值改写 |
| 类型和平台范围 | `contracts/formatting-model.json` 生成各端类型；公众号仅开放给本站原稿 | 缺少模式的旧记录按平台行为读取，保留旧请求指纹与已确认稿 |
