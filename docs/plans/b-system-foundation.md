# B 独立系统基础

独立后台和 CSDN 草稿子范围可运行。完整首期关口见[总计划](../implementation-plan.md)，本地与真实证据见[验收记录](../acceptance.md)。

| 任务 | 当前实现与证据 | 剩余事项 |
| --- | --- | --- |
| B01 工程与 CI | WSL 启停、固定工具、工作区、隔离数据库和 CI 全量验证。见[开发说明](../development.md)、[CI](../../.github/workflows/ci.yml) | 完整多平台写入适配与内部契约随 C 阶段核对 |
| B02 数据模型 | 已实现用户、账号、连接、快照、任务、父分发、租约、状态与迁移。见[账号归属](../account-ownership.md)、[任务模型](../../apps/api/model.go) | 增补其他发布平台及完整外站审核与副本状态 |
| B03 本站认证 | 已有独立用户登录、服务端会话、同源校验、用户管理与数据隔离。见[用户接口](../api.md#用户管理) | 目标环境的凭据恢复和轮换随 E03 演练 |
| B04 来源登记 | 固定邀请审批、签名激活、最小权限、轮换、取消及守卫。见[外部手册](../external-integration.md) | 真实调用方 HTTPS 联调及新增目标权限验证 |
| B05 不可变确认 | 来源快照、平台稿修订、指纹和确认冻结已实现，CSDN 可按配置接收正文图片 | MDX 和其他平台兼容预览，以及双方确认一致性 |
| B06 持久化调度 | 账号互斥、租约、有限重试、取消、父子任务及来源恢复已实现 | 完整多平台写入的部分成功和独立恢复，真实调用方断网与重启 |
| B07 执行器 | 账户范围的领取、心跳、进度和结果接口，运行及异常清理有合成回归。见[执行器](../../apps/worker/src)与[内部接口](../api.md#内部执行器接口) | 补充每个新增适配器的边界、提交故障和进程回收用例 |
| B08 账号与验证 | CSDN 与小红书账号独占、会话隔离及无桌面远程登录。见[账号管理](../platform-accounts.md) | 不同真实账号、主动失效、额外验证和目标环境远程登录 |
| B09 日志与健康 | 已有任务日志、对象处理记录、来源审计、只读设置与执行器健康信息。见[运维](../operations.md) | 完整系统日志、保留策略、积压及磁盘监测 |
| B10 后台框架 | 独立认证、导航、状态、焦点与窄屏具备组件和浏览器验证。见[后台规范](../admin-ui.md) | 新页面随功能继续按同一规范检视 |
| B11 概览与记录 | 总览、平台任务、对象处理记录及日志可筛选与定位 | 多平台发布及审核汇总、部分失败与长列表异常验收 |
| B12 来源与账号界面 | 账号工作台、来源审批、平台稿编辑确认、分发和验证已接入真实 API | 其他平台分发稿和完整系统设置 |

B 阶段结束前，使用模拟来源和多平台适配器复核任务、权限、确认、等待恢复及日志闭环。真实平台及调用方验收分别归入 C、D。
