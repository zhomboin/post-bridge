# 账号归属与认证存储

## 归属边界

本站用户与平台身份分别建模。users 保存本站身份、密码哈希、角色和启用状态；account 保存平台身份和唯一所属用户。管理员权限用于用户管理，不默认授予其他用户的平台账号、文章或任务操作权限。

同平台可有多个账号。网页新增账号先待核验，未核验不占用其他用户真实身份；官方登录核验后通过平台用户名及稳定用户标识唯一约束确立独占归属。未核验账号不能创建任务和授予来源权限。账号内部标识和所属用户不可变，不能通过修改显示名称、解绑或配置导入改变所属用户。需要核对真实身份时使用平台官方页面或账号接口，昵称不作为身份依据。

## 数据关系

| 数据 | 关联与保护 |
| --- | --- |
| sessions | 绑定 user_id、认证版本和过期时间；令牌只保存哈希 |
| account | 绑定 owner_user_id；数据库拒绝归属和平台身份替换 |
| account_connections | 绑定账号和连接版本，保存受控会话引用和执行凭据哈希 |
| jobs | 正式列记录所属用户、账号、连接版本及发起者；用户与账号有组合外键约束 |
| 文章、笔记、发布设置 | 以账号作为存储和查询边界，不以用户名或文章编号单独定位 |
| 日志、处理快照 | 通过所属任务隔离，列表、搜索和数量统计也受限制 |
| 来源应用、稿件及分发 | 归属用户；授权账号必须属于同一用户 |
| 来源状态与撤销记录 | 用户、来源、原稿共同定位，互不影响其他用户的同名来源 |

来源执行逐一核对本次目标账号，解绑一个账号不影响其他有效授权账号。保存来源授权时只保留当前可用的已验证账号。

用户请求的去重范围为所属用户、调用主体和请求标识，账号及内容纳入指纹。已有请求重放取得同一任务，不能因升级重复创建任务。

## 本站认证

管理员初始化密码从仓库外私有文件读取。用户密码使用 bcrypt 哈希保存；登录按用户名查询对应用户，不使用全局固定密码。管理员可创建普通用户、停用用户和重置密码，不开放匿名注册。

登录成功创建十二小时服务端会话。浏览器保存 HttpOnly、SameSite=Strict Cookie，HTTPS 下开启 Secure；数据库保存令牌哈希、CSRF 和有效期。写接口校验同源和 CSRF。用户停用或密码重置提升认证版本并清除会话，已有凭据不能继续登录。

每次数据库操作使用独立事务设置用户及账号范围，事务结束清理范围，连接池不保留上一请求身份。业务表强制启用行权限；应用启动拒绝超级用户和可绕过行权限的数据库角色。初始化、后台维护及已校验的用户管理使用明确的服务端维护范围。

## 平台会话与执行器

浏览器会话保存在 worker 私有存储中，不写入账号元数据表。新增连接目录由服务器引用和 worker 根目录共同确定，用户不能提供任意路径。账号目录、执行器凭据和浏览器上下文各自独立，不共享 Cookie。

账号根目录保留互斥锁和执行器身份，browser 子目录保存有效浏览器数据。候选登录目录在核验成功后替换有效目录；关闭或提交失败恢复原会话。本站退出仅结束相关远程登录入口，已确认的平台会话继续供授权后台任务使用。

调度器持有内部调度凭据，向账号子进程提供该账号、该连接的执行凭据。API 通过数据库哈希核验并检查用户、账号和连接是否有效，执行器不能访问其他账号任务或调度器接口。浏览器执行名额覆盖任务及远程登录，租约过期可回收。

Ubuntu 安装器为仅 worker 用户组可执行的项目私有 bubblewrap 副本设置应用级用户命名空间许可，保持系统全局限制。CI 同样使用专用副本，并在禁止提权条件下验证，避免依赖 WSL 的宿主策略。

每个账号运行于独立文件系统和进程命名空间，只挂载运行文件、浏览器及自身会话。账号执行环境看不到其他账号目录和调度器配置，不接收应用数据库连接凭据。停止服务需等待子执行器和浏览器结束；异常账号单独恢复。

解绑撤销执行权限和连接，停止未执行任务；尚未确认的外站结果须先核对或人工结束，服务端拒绝此时解绑。执行器在关闭后清理撤销连接的凭据，历史业务数据保留。暂停本站用户不清除其有效平台会话，重新启用仍需重新登录本站。

私有目录不是应用加密凭据库。部署应使用加密存储卷和加密备份，将会话与恢复资料限制给运维人员；备份按保留策略到期清理。运行环境中的受信任调度器和系统管理员仍属于运维信任边界。

## 数据迁移与验收

升级前停止执行器，备份数据库、服务私有配置和账号会话。初始化事务把已有账号、任务、文章与来源归入初始化管理员，保留账号及任务标识、内容和平台会话；迁移标记防止重复归属。账号会话首次使用时在持有账号锁的情况下整理为有效目录，不复制到仓库。

本地启动器仅处理自身专属 PostgreSQL 集群，为 API 配置非超级用户应用角色。外部数据库的角色权限、对象所属者和备份恢复由数据库管理员按[部署说明](ubuntu-deployment.md)准备，不由 API 擅自调整。

验收覆盖两个用户、同平台多账号、跨用户对象读取与修改、列表和统计、连接池并发复用、已有请求重放、重复迁移、解绑后旧凭据拒绝、相同来源编号隔离、候选登录失败保留会话以及真实 Chromium 沙箱隔离。生产环境另行验证备份恢复和平台登录，不以合成数据代替真实验收。

本地业务环境已完成备份恢复演练及实际归属迁移，原管理员和 CSDN 会话检查通过；多用户合成验证使用恢复副本，业务库保留原有用户与平台账号。当前结果及未验边界见[验收记录](acceptance.md)。
