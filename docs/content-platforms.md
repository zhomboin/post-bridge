# 内容平台接入与通用服务

## 当前范围

账号内容共用查询、任务创建、幂等合并、租约、取消、身份校验和事务存储。CSDN 文章与小红书笔记的后台页面使用统一接口，专属字段由各自展示组件读取。通用工作台支持其他已注册平台的列表、筛选、分页、独立文本正文和返回位置。

正式平台注册 CSDN 与小红书。合成平台只存在于测试中，不提供真实账号登录或发布能力。平台支持某项操作仍需满足账号归属、有效连接与调用入口授权；外部来源仍只开放获批的 CSDN Markdown 草稿保存。

## 数据约定

- 内容由平台账号和字符串远端标识定位，不要求数字 ID。账号绑定的平台不可替换。
- 内容形式与正文格式分别声明。未知平台状态保留原值，只有明确的平台校验规则才可确认已发布等状态。
- 指标含值、单位和可选统计周期。缺失值为 null，不补零；各平台负责校验计数、净变化和具体含义。
- 平台扩展必须是受限 JSON 对象。自定义字段需要相应校验函数；未声明的扩展不进入通用存储。
- 平台图片仅通过明确媒体规则放行，通用代码不根据 GET 或 POST 推断请求安全。正文不进入任务、列表或日志。
- 账号资料与统计是可选数据，不是列表同步的必填内容。现有两个适配器仍在一次同步中采集其已支持的资料和统计。

## 同步、缓存与兼容

列表和详情 GET 只读取数据库；首次读取已有账号时，在账号事务中建立公共投影，保留原采集时间。完整同步在同一事务替换列表，部分同步只更新已取得条目，不移除缺失内容。失败、取消、无效租约、错误账号或失效连接不能覆盖数据。

公共采集器要求明确的完成标记，支持不透明游标；重复条目、循环游标、总数变化、身份变化、超量或未完成结果均报错，不冒充完整快照。原生翻页和请求白名单仍由平台适配器控制。

CSDN 完整同步清空正文缓存，正文查询与维护按 30 天处理；小红书正文在同步时保留，读取失败不清空。缓存行为由平台注册声明决定。

文章和笔记专属接口继续可用，新旧读取任务入口共用幂等记录和活动任务。公共表使用账号行权限，平台专属表保留用于兼容；新增平台使用公共表，无需新增一套列表、正文和快照表。不要手工清空平台表、公共表或任务记录。

## 新平台接入步骤

1. 核实实际支持的读取、草稿或发布能力，明确内容形式、正文格式、标识、分页、状态、媒体和字段限制。不能根据另一个平台推断能力。
2. 增加平台声明与 API 注册项；实现状态、专属字段、正文和媒体校验。仅使用公共字段时无需平台专属表或查询接口。
3. 在 worker 注册入口增加执行实现。会话只需提供执行和关闭方法，官方 API 实现不依赖浏览器配置；使用浏览器时复用浏览器会话工具。登录方式、平台请求边界和写入确认由对应平台明确实现。
4. 使用公共内容结果和公共采集器。页码、游标或原生翻页转换由平台完成，公共任务与存储流程保持不变。
5. 后台默认使用通用工作台；有专属字段、图片展示或复杂表单时增加对应展示组件，不复制查询、刷新和幂等动作。
6. 生成契约，补齐正常、边界、异常及权限用例；验证不需要修改公共路由、任务调度和存储方法。新增一种公共业务能力时才扩展公共层。

在已准备好的 WSL 或 Ubuntu 开发终端中逐条执行：

```bash
npm run contracts:generate
npm run contracts:check
npm run typecheck
npm run build
npm run format
npm run format:check
```

本地数据库验证仅使用私有临时配置，具体准备见[开发说明](development.md)。全量用例和契约一致性由 GitHub CI 检查。

## 验证与代码检视

合成平台使用不同于正式平台的文档形式、含分隔符的非数字 ID、不透明游标和无浏览器执行会话，覆盖未知状态、缺失指标、能力缺失、取消、失租、账号隔离、部分同步与完整替换。后端验证行权限、HTTP 会话与 CSRF、新旧入口幂等及兼容投影；后台浏览器覆盖列表、正文文本安全、返回路径、键盘和 390／320 窄屏。

| 调整前 | 调整后 | 原因 |
| --- | --- | --- |
| 页面分别提交同步与正文请求 | [公共动作](../apps/admin/src/content-task.ts)按账号和路径保留失败重试标识 | 避免重复维护幂等逻辑与跨账号复用请求 |
| 平台列表有不同存储与分页流程 | [公共存储](../apps/api/content_store.go)负责数据库查询，专属表仅用于兼容 | 新平台无需复制列表服务 |
| 执行入口按平台分支并创建所有适配器 | [平台注册](../apps/worker/src/content-platforms.ts)只打开当前平台会话 | 缩小平台修改范围并支持无浏览器执行 |
| 文章类型依附页面文件 | [独立展示类型](../apps/admin/src/article-types.ts)与共享生成契约分别维护 | 减少页面之间的实现依赖 |
