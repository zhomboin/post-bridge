# 多平台内容转换方案

## 目标和范围

PostBridge 接收经授权的 Markdown 原稿，独立生成可预览、可核对的平台稿。先对照 CSDN 同步助手的微信公众号文章效果，再对照小红书图文笔记，形成可复现的转换规则；不将 CSDN 扩展或 MCP 接入运行链路。详细任务和顺序见[实施计划](plans/platform-formatting.md)。

本阶段交付本地候选稿、预览、差异提示、人工编辑和确认，不开放微信公众号或小红书远端写入。上传、草稿保存、账号身份核对、未知结果恢复及公开发布由各平台既有或后续独立方案负责；本地转换成功不能表示远端保存或发布成功。小红书长文与图文是不同目标，本阶段只对照图文。

已取得综合合成稿的一次 CSDN AI 输入输出及多类型离线预处理结果，尚未验证公众号草稿或完整平台限制；不承诺像素、字节或所有平台行为完全一致。实现依据可观察行为独立编写，不复制未经授权的源码、提示词、样式模板、图标或素材。

## 现有基础

[格式化](ai-formatting.md)对 CSDN 稿保护代码、链接、图片、公式和表格，为小红书生成本地正文、话题和卡片，为公众号提供独立的保真转换与可选 AI 辅助建议。API 管理任务、修订、授权和模型调用；formatter 分析 Markdown、独立校验转换及渲染卡片。

小红书 20 个 UTF-16 单元标题、正文与话题共 1000 个单元及卡片数量等是现行内部预览限制，不当作平台已验证限制。来源双层 AI 授权、冻结内容、确认修订、账号隔离及失效守卫继续有效。

## 样本采集

### 采样环境和边界

使用自编合成文章及合成图片；记录采样日期、扩展版本及来源、浏览器主版本、目标平台和内容类型、入口、采样阶段、是否人工修改或使用 AI。每轮固定环境和输入。扩展或平台变化后重跑关键样本，不把不同版本的观察混为同一结论。

优先观察无需登录或外站写入的输入及转换预览。若只能从已发布的 CSDN 文章发起，先查可直接输入或预览的入口；不能为样本擅自公开发布。现有指定 CSDN 账号的登录、草稿和只读授权继续有效；微信公众号、小红书等其他平台账号和草稿写入须取得明确授权，删除草稿另需授权。不可用的阶段标为未采集，不猜测输出。

私有原始采样、截图、账号与配置只放在经批准的本地私有目录；不得提交凭据、原始平台响应、真实标识、地址或敏感截图。仓库测试夹具仅使用独立编写且可公开的合成素材和预期，受版权或隐私限制的原始输出不入库。采集优先使用界面可见内容与正常复制导出，不采集 Cookie、令牌、验证码或登录画面。

### 样稿矩阵

| 样稿 | 输入覆盖 | 核对重点 |
| --- | --- | --- |
| 基础 | 标题、摘要、各级标题、段落、中英文 | 顺序、层级、间距和字词 |
| 列表 | 多级有序、无序、引用、任务列表 | 层级、编号及不支持项 |
| 技术内容 | 行内代码、多语言代码、长行、特殊字符 | 空格、换行、内容及转图后的可读性 |
| 结构 | 表格、链接、锚点、公式 | 单元格、目标地址和无法表达的内容 |
| 素材 | 多张不同尺寸合成图片 | 数量、顺序、比例和转存行为 |
| 边界 | 空字段、长标题、连续空行、Emoji、未知扩展 | 限制、截断、提示与字符计数 |

每份样稿保存编号、输入及预期内容清单。记录 CSDN 可见预览、目标编辑器及保存后重开三个阶段；缺失阶段保持空缺。获取页面允许导出的 HTML 时只保留必要的脱敏正文；只能截图时不推断底层结构。相同输入生成 PostBridge 候选稿，逐项记录差异来源。

### 对照与通过条件

文本和结构检查标题、摘要、段落、顺序、数字、条件、否定、代码空白、链接目标及图片对应关系；视觉检查层级、溢出、图片比例与代码可读性。截图差异只辅助检查，不能代替内容核对。分别记录 CSDN 转换、目标平台清理和 PostBridge 输出，避免把平台自身变化归因于转换。

代码、事实、条件、链接目标或重要图片丢失为阻断；不支持或可能遗漏为人工核对；不影响理解的排版差异可接受；缺少证据为无法判断。每个样稿记录具体差异和处理结论，阻断项清零才允许相应本地能力验收。人工确认不能替代真实平台草稿验收。

## 转换流程

1. 按用户和来源授权保存原稿快照、目标与内容指纹，按顺序分析 Markdown 内容块，保留原文、代码、链接和图片关系。
2. 根据目标和模式执行确定性转换；仅在用户选择且具备授权时使用 AI 整理候选内容。
3. 对转换结果做结构、内容保真、素材、平台规则及安全校验，生成问题与原稿块映射。
4. 展示本地预览和问题，用户编辑并确认。确认绑定平台、模式、修订、最终内容、素材、规则与提示词版本；改稿或重生后重新确认。
5. 对不支持或无法核对的内容阻断或列明人工处理，不静默截断、改写、丢失或推断远端状态。

各平台规则分别标记来源为官方要求、真实实测或本项目内部保守限制。发布能力、账号和平台限制以对应平台和目标账号的验证为准。

### 微信公众号

第一阶段保留标题、摘要、正文及素材映射，使用白名单将常见 Markdown 结构转换为安全富文本。代码保留原文和语言；经样本证明需要图片时，可新增完整代码图片及原块映射，长代码不得裁切。表格或公式无法保真时明确提示或阻断。图片仅引用经过批准的素材，目标平台转存需单独验证。本地预览不代表素材已上传。

不让模型生成可执行 HTML、脚本、任意 CSS 或图片地址。预览内容净化并隔离，不加载未经批准的外部资源；目标平台会二次处理时，以其保存后草稿为真实效果。

### 小红书图文

以现有正文、话题、封面、卡片及原块引用为基础，对照 CSDN 的取舍、顺序、分页、代码和遗漏。保留现有完整代码引用、溢出提示、人工编辑及确认能力；规则更新不能改变已确认修订。不能完整表达时提供可定位的遗漏清单，不用虚构内容填补。

## 提示词和校验

公众号默认仅做无模型保真转换。可选 AI 辅助只建议基于原文的标题、摘要及引用原块的结构建议；禁止修改代码、链接目标、图片地址、公式和事实，无法确认返回问题。结果由程序校验并经用户选择，不直接覆盖原正文。

小红书 AI 按原文提炼短段与卡片，引用支持内容的原块；保留条件、否定和不确定性，不虚构经历、收益、测试或图片。代码只引用完整原始块，未纳入的重要内容列入遗漏。严格 JSON 校验字段、长度、重复和块引用；引用存在不能证明事实正确，仍需人工审核。

调整提示词时固定合成样稿多次比较事实、遗漏和稳定性，升级提示词版本；同样固定规则版本。既有模型调用已发送但结果未知时不自动重发。

## 验收和文档生命周期

依次验收样稿、可观察 CSDN 输入输出、本地确定性转换、后台与授权、授权后真实草稿对照。真实账号不可用时保留待验，不将合成测试表述为真实平台或生产通过。自动写入和发布另行验收账号、上传、幂等、断线、未知结果与授权撤销。

本方案、[实施计划](plans/platform-formatting.md)和[对照记录](plans/platform-formatting-observations.md)是临时专项文档。整个任务完成并经用户确认后，先把仍适用的使用、规则、验收和运维结论写入长期文档及简要版本记录，再删除专项文档并清理全部入口。未确认全部完成前保留计划与未完成项。
