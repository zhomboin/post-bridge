# AI 平台稿格式化

## 使用范围

可选接入 DeepSeek，将授权 Markdown 原稿整理为 CSDN 平台稿，或生成小红书正文、话题、封面和文字卡片。参考现有工具的处理方式自行实现，没有使用参考项目源码、提示词或模板。

基础草稿、账号读取和分发不依赖模型。AI 任务独立排队，关闭页面后继续；正文和图片仅在所属用户登录后可读取。

小红书只生成本地图文素材，不上传、不创建远端草稿、不发布。MDX、AI 绘图及从已同步文章自动搬运不在范围内。

## 页面操作

1. 在“格式化稿”新建原稿，填写标题与 Markdown，选择目标平台。生成 CSDN 稿时选择所属账号。
2. CSDN 生成后核对原稿与结果，采用后可继续编辑，或在详情确认保存至 CSDN 草稿箱。来源稿采用为新平台稿修订，仍通过原有确认和签名分发。
3. 小红书生成后核对正文、话题、封面、每张图片及删减清单。编辑内容、调整顺序、拆分卡片或更换样式后，保存并重新排版。
4. 完整代码超出一张图片时，可在卡片编辑中取消保留该代码块，删减清单会明确记录；不要以裁切代替核对。
5. 核对图片后确认当前图文修订，可逐张下载。确认不会触发平台写入。
6. 从列表或详情链接恢复查看。未完成、失败、取消、待调整和已采用分别显示。

来源平台稿中的 AI 入口要求应用授权与单篇授权同时有效。未保存的平台稿编辑先保存，再生成候选稿。生成不会直接替换人工稿；采用时检查基础修订，冲突后须重新核对。

## 内容规则

| 平台 | 处理 |
| --- | --- |
| CSDN | 保留正文文字顺序，允许标题层级、换行、列表和加粗；代码、链接、图片、公式和表格受保护。摘要与标签从原稿提取。 |
| 小红书 | 正文与卡片分开组织，每张卡片关联原稿内容块；完整代码按引用展示。未进入卡片的内容列入核对清单。 |
| 卡片 | 1080×1440，提供技术笔记和操作清单；按实际高度分页，超过容量时要求人工调整，不裁切正文或无限缩小字号。 |

小红书采用保守图文规则：标题最多 20 个 UTF-16 单元，正文拼接话题后最多 1000 个，最多 8 个话题、8 张正文卡片加封面。属于内部预览规则，真实发布入口限制仍须单独验收。

CSDN 继续使用现有标题、正文和发布预设校验。模型格式化后的正文需通过解析器保真检查；事实、措辞和小红书精简仍需人工核对。

## 任务、修订与资源

默认原稿处理上限 30000 字，模型最大输出 16384 token；全局最多两个任务，每用户同时一个，排队最多五个。每日每用户默认预留额度 300000 token，响应正常返回后按实际用量核销；中断用量保留预留，避免重复发送造成额外费用。

会话最多有效 24 小时，来源稿不会超过原有授权期限。到期后停止读取、采用和确认，清理窗口为其后 24 小时；已创建的平台任务保留自身快照。图片在 PostgreSQL 中按用户和修订隔离，单次最多 12 MiB，每用户素材最多 64 MiB。

重新排版只使用已保存内容，不调用模型。编辑后生成新修订，取消当前确认；已确认修订另存，图片摘要和顺序保持可核对。源码模板升级不会重绘已有图片。

模型已发送但响应未知时不自动重复请求。取消、服务中断、来源撤销和账号停用会阻止结果采用；没有外站操作时也不显示已分发。

## 服务与私有配置

| 配置 | 用途 |
| --- | --- |
| AI_FORMATTING_ENABLED | 可选开关，默认关闭 |
| AI_PROVIDER_CONFIG_FILE | 0600 模型配置，包含 model 与 api_key_file |
| DEEPSEEK_API / DEEPSEEK_API_KEY | 本地 API 可读取已有环境凭据，不传给其他服务 |
| FORMATTER_URL / FORMATTER_TOKEN_FILE | 回环渲染服务与私有认证 |
| FORMATTER_ADDR | 渲染服务监听地址 |
| FORMATTER_FONT_FILE / FORMATTER_CODE_FONT_FILE | 可选本地字体文件 |

模型配置还可设置 max_input_characters、max_output_tokens、daily_tokens、max_in_flight、timeout_seconds；范围由 [配置校验](../apps/api/formatting_config.go)限定。默认模型 deepseek-flash，可在私有配置调整。

API 管理模型调用、任务和数据库。formatter 仅分析 Markdown 与渲染卡片，临时 Chromium 不使用平台登录目录；平台 worker 不接收模型和渲染凭据。部署停止会回收各自进程。

完整启用步骤见[本地开发](development.md#deepseek-格式化)和[Ubuntu 部署](ubuntu-deployment.md#deepseek-格式化)。备份数据库、私有模型配置和密钥，恢复后检查账号、格式化稿和素材权限；不备份临时浏览器目录。

## 接入与验证

外部来源在应用授权中明确允许 AI 处理及目标平台，单篇准备稿的 formatting 声明 allow_ai_processing、platforms，以及可选 auto_generate。本篇目标必须包含在应用获准范围内；原有请求缺少声明时不发送原文给模型。原稿指纹与 CSDN 确认算法保持兼容，小红书不加入分发目标。

自动生成使用持久化待办，接收原稿后异步创建任务；失败和配额限制不会升级平台操作。接口见 [API](api.md)、[外部手册](external-integration.md)与[格式化模型契约](../contracts/formatting-model.json)。

代码和隔离数据库用例覆盖正常、幂等、取消、超时、来源授权、内容保护、修订和图片读取。真实 DeepSeek 已用合成 CSDN 与小红书样稿验证；没有据此执行真实平台写入或生产部署。
