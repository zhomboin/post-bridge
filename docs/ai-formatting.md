# AI 平台稿格式化

## 使用范围

可选接入 DeepSeek，将授权 Markdown 原稿整理为 CSDN 平台稿，或生成小红书正文、话题、封面和文字卡片。微信公众号默认做本地保真排版，启用 DeepSeek 后可为当前原稿另行授权生成辅助建议。参考现有工具的可见行为独立实现。

基础草稿、账号读取和分发不依赖模型。AI 任务独立排队，关闭页面后继续；正文和图片仅在所属用户登录后可读取。

小红书只生成本地图文素材，微信公众号只生成本地稿，均不上传、不创建远端草稿、不发布。MDX、AI 绘图及从已同步文章自动搬运不在范围内。

## 页面操作

1. 在“格式化稿”新建原稿，填写标题与 Markdown，选择目标平台。生成 CSDN 稿时选择所属账号。
2. CSDN 生成后核对原稿与结果，采用后可继续编辑，或在详情确认保存至 CSDN 草稿箱。来源稿采用为新平台稿修订，仍通过原有确认和签名分发。
3. 小红书生成后核对正文、话题、封面、每张图片及删减清单。编辑内容、调整顺序、拆分卡片或更换样式后，保存并重新排版。
4. 完整代码超出一张图片时，可在卡片编辑中取消保留该代码块，删减清单会明确记录；不要以裁切代替核对。
5. 核对图片后确认当前图文修订，可逐张下载。确认不会触发平台写入。
6. 从列表或详情链接恢复查看。未完成、失败、取消、待调整和已采用分别显示。
7. 选择微信公众号并填写原稿。默认使用保真排版；需要标题、摘要、结构或核对建议时，选择 AI 辅助建议并确认允许 DeepSeek 处理本篇原稿。建议单独显示，用户按需参考。
8. 通过正文差异核对原稿与候选稿。可编辑候选稿、逐张选择本地 PNG 或 JPEG 素材，再保存并重新排版。核对预览和问题后复制排版内容，或确认无阻断问题的本地修订。

来源平台稿中的 AI 入口要求应用授权与单篇授权同时有效。未保存的平台稿编辑先保存，再生成候选稿。生成不会直接替换人工稿；采用时检查基础修订，冲突后须重新核对。

## 内容规则

| 平台 | 处理 |
| --- | --- |
| CSDN | 保留正文文字顺序，允许标题层级、换行、列表和加粗；代码、链接、图片、公式和表格受保护，英文列表项之间保留词边界。摘要与标签从原稿提取。 |
| 小红书 | 正文与卡片分开组织，每张卡片关联原稿内容块；完整代码按引用展示，重复引用会被拒绝。未进入卡片的内容及需要核对的链接目标列入核对清单。 |
| 微信公众号 | 尽量保留原稿结构，图片按来源顺序和位置映射到用户选择的本地素材；未提供或无法安全转换的内容列入核对提示。 |
| 卡片 | 1080×1440，提供技术笔记和操作清单；按实际高度分页，超过容量时要求人工调整，不裁切正文或无限缩小字号。 |

小红书采用保守图文规则：标题最多 20 个 UTF-16 单元，正文拼接话题后最多 1000 个，最多 8 个话题、8 张正文卡片加封面。属于内部预览规则，真实发布入口限制仍须单独验收。

小红书生成优先整理原稿中可表达的内容，局部格式不适合图文时保留其他内容并列明需要核对的部分；重要信息可能丢失或造成误解时仍需人工处理。

小红书新增原稿没有的评论区、主页或私信指引时，候选稿提示核对并暂停生成卡片。编辑去除该指引后可继续排版。

小红书原稿含 HTML 时，内容按受保护块处理，不执行其中脚本；未原样绘制的部分列入核对清单。CSDN 格式化继续使用现有的 HTML 内容限制。

CSDN 继续使用现有标题、正文和发布预设校验。模型格式化后的正文需通过解析器保真检查；小红书生成要求保留虚构、假设和未验证等限定，卡片代码块通过原文引用展示。提示词不能保证模型遵循约束，事实、措辞、代码和小红书精简仍需人工核对。

## 任务、修订与资源

默认原稿处理上限 30000 字，模型最大输出 16384 token；全局最多两个任务，每用户同时一个，排队最多五个。每日每用户默认预留额度 300000 token，响应正常返回后按实际用量核销；中断用量保留预留，避免重复发送造成额外费用。

会话最多有效 24 小时，来源稿不会超过原有授权期限。到期后停止读取、采用和确认，清理窗口为其后 24 小时；已创建的平台任务保留自身快照。图片在 PostgreSQL 中按用户和修订隔离，单次最多 12 MiB，每用户素材最多 64 MiB。

重新排版只使用已保存内容，不调用模型。编辑后生成新修订，取消当前确认；已确认修订另存，图片摘要和顺序保持可核对。源码模板升级不会重绘已有图片。

公众号候选稿使用独立 Markdown 和修订，不覆盖原稿。最多关联 20 张 PNG 或 JPEG，图片合计不超过 4 MiB，单张宽高不超过 4096 像素且像素总数不超过 1200 万；素材由本站按用户和会话有效期隔离保存，不自动访问原图地址。编辑或更换素材后需重新核对并确认；来源相同的重复图片在位置发生歧义时需要重新选择。

AI 辅助只提交原稿标题、摘要及内容块的文本与位置。受保护块仅提交位置和类别。建议使用受限的纯文字字段，结构建议与问题均引用原稿段落；正文仍按本地保真规则生成。修改候选稿后重新排版沿用原稿的建议，无需再调用模型。新候选修订保存平台、模式、规则和提示词版本、模型及素材摘要。

公众号预览和复制使用相同的内容白名单，只显示当前修订绑定的本地图片；不可安全显示的图片以文字提示代替，其他不支持的内容保留为可核对文本。预览在隔离框架中显示。

转换后会单独核对来源块顺序，以及 Markdown 和常见 HTML 的正文、代码、安全链接与图片占位；发现差异时保留候选稿并提示对照原文。普通正文比较忽略空白差异，代码按原文检查；未知标签和行内 HTML 等无法完整自动核对的内容需人工查看。自动检查不能代替对事实、图片内容和实际平台显示的核对。

模型已发送但响应未知时不自动重复请求。取消、服务中断、来源撤销和账号停用会阻止结果采用；没有外站操作时也不显示已分发。

API 异常退出后，已排队的格式化任务保存在数据库中。执行中的任务在租约到期后标记为处理已中断，不自动重试；同一用户的排队任务随后可继续。重复提交原生成请求会返回原任务。

来源授权或所属平台账号失效后，任务列表不再显示原文章标题，详情与采用入口不可用；状态恢复仍以当前授权和账号状态为准。

提示词或规则升级后，尚未执行的旧版本任务会中断，避免把新版结果标记成旧版；旧任务需要新建生成任务，不能直接使用新版规则重新排版。已完成的修订不会自动重绘。

## 服务与私有配置

| 配置 | 用途 |
| --- | --- |
| AI_FORMATTING_ENABLED | 启用 CSDN、小红书及公众号 AI 辅助，并启用本地保真排版，默认关闭 |
| CONTENT_FORMATTING_ENABLED | 仅启用本地公众号转换，默认关闭；不需要模型密钥 |
| AI_PROVIDER_CONFIG_FILE | 0600 模型配置，包含 model 与 api_key_file |
| DEEPSEEK_API / DEEPSEEK_API_KEY | 本地 API 可读取已有环境凭据，不传给其他服务 |
| FORMATTER_URL / FORMATTER_TOKEN_FILE | 回环渲染服务与私有认证 |
| FORMATTER_ADDR | 渲染服务监听地址 |
| FORMATTER_FONT_FILE / FORMATTER_CODE_FONT_FILE | 可选本地字体文件 |

模型配置还可设置 max_input_characters、max_output_tokens、daily_tokens、max_in_flight、timeout_seconds；范围由 [配置校验](../apps/api/formatting_config.go)限定。默认模型 deepseek-flash，可在私有配置调整。

API 管理模型调用、任务和数据库。formatter 仅分析 Markdown 与渲染卡片，临时 Chromium 不使用平台登录目录；平台 worker 不接收模型和渲染凭据。部署停止会回收各自进程。

完整启用步骤见[本地开发](development.md#deepseek-格式化)和[Ubuntu 部署](ubuntu-deployment.md#deepseek-格式化)。备份数据库、私有模型配置和密钥，恢复后检查账号、格式化稿和素材权限；不备份临时浏览器目录。

## 接入与验证

外部来源在应用授权中明确允许 AI 处理及目标平台，单篇准备稿的 formatting 声明 allow_ai_processing、platforms，以及可选 auto_generate。本篇目标必须包含在应用获准范围内；原有请求缺少声明时不发送原文给模型。原稿指纹与 CSDN 确认算法保持兼容，小红书不加入分发目标。

自动生成使用持久化待办，接收原稿后异步创建任务；失败和配额限制不会升级平台操作。接口见 [API](api.md)、[外部手册](external-integration.md)与[格式化模型契约](../contracts/formatting-model.json)。

代码和隔离数据库用例覆盖正常、幂等、取消、超时、来源授权、内容保护、兼容与图片读取。公众号 AI 辅助通过合成模型响应和实际 formatter 回归；真实 DeepSeek 已用合成 CSDN 与小红书样稿验证。多样稿模型效果、真实公众号草稿与目标部署的证据见[验收记录](acceptance.md#ai-格式化)。
