# 平台账号管理

## 用户与账号

用户通过本站账号和密码登录。管理员在“用户管理”创建、启用和停用用户；普通用户不具备用户管理权限。用户停用或重置密码后，已有本站登录会话失效。

每个用户可以绑定同一平台的多个账号，一个真实平台账号只归属一个用户，不提供共享、转让或替换身份。解绑保留账号归属及处理记录；原用户可在没有未核对外站结果时重新绑定。其他用户不能接管该身份。

平台能力保持独立：CSDN 支持文章、统计、正文、草稿和受控发布；小红书支持登录检查、远程登录和笔记只读同步，不开放正文读取、上传、草稿、发布、编辑或删除。外部来源仅执行 CSDN Markdown 草稿，每次请求选择一个已获授权的账号。

## 绑定与登录

1. 按[开发说明](development.md)或[Ubuntu 部署](ubuntu-deployment.md)启动服务，以自己的用户登录。
2. 打开“平台账号”，选择“绑定账号”，填写平台、预期平台用户名或小红书号、显示名称。
3. 进入该账号的“账号设置”，开始远程登录，在官方页面完成扫码或平台验证。
4. 服务端核验登录身份后才确立独占绑定并开放内容任务；仅填写用户名不能占用其他用户真实身份。小红书稳定用户标识由执行器从官方账号信息取得，不要求用户填写 Cookie 或平台密码。
5. 登录成功后检查账号状态，再同步文章或笔记。新建 CSDN 草稿时选择具体发布账号；来源授权也从自己的账号中选择。
6. 解绑时核对当前账号并确认。新任务停止，执行器关闭浏览器并清理已撤销的会话和内部凭据；文章、快照和处理记录保留。尚未确认的外站结果须先核对或人工结束，服务端会拒绝此时解绑；解绑不会撤销外站内容。

同一账号的登录和任务互斥；浏览器执行名额上限为全局八个、每用户两个，等待不占用浏览器。账号绑定上限为每用户一百个。

## 存储与隔离

账号身份、归属和状态保存在 PostgreSQL。每次业务数据库操作在事务中设置当前用户，账号、任务、文章、日志、统计和来源记录通过数据库行权限隔离。API 数据库角色不得为超级用户或具有 BYPASSRLS 能力。

认证连接保存会话目录引用、连接版本和内部执行凭据哈希，不向网页返回 Cookie、浏览器目录或执行密钥。新增会话在 worker 的私有根目录中按用户、账号和连接版本分别保存；实际浏览器数据位于各连接目录的 browser 子目录。

重新登录使用候选目录，只有身份核验通过、浏览器关闭并完成保存后才替换有效会话；失败或取消不覆盖有效会话。任务记录具体账号和连接版本，已撤销连接的执行器及结果上报被拒绝。

调度器读取账号范围，为每个账号启动独立的 bubblewrap 执行环境。子进程只看到代码运行文件、浏览器和自己的会话目录，不接收数据库、管理员或来源存储密钥。私有目录权限为 0700，凭据文件为 0600；存储卷和备份的加密由部署环境提供。详见[账号归属与认证存储](account-ownership.md)。

## 可选私有配置导入

网页绑定的账号无需编辑账号配置文件。需要复用已验证的专属会话时，可在仓库外维护导入配置，使用[模板](../deploy/platform-accounts.example.json)。不得导入个人日常浏览器目录。

导入前备份数据库、私有配置及全部账号会话，确认原目录没有浏览器使用。将会话复制到独立私有目录，保留原目录作为恢复依据；导入使用独立内部凭据，原账号配置继续保留。重启前确认没有未完成任务，重启后核对所属用户和原有数据，再运行登录检查与只读同步。

| 字段 | 内容 |
| --- | --- |
| accounts | 额外导入的账号列表，可包含多个 CSDN 或小红书账号 |
| id | 不变的内部账号标识，不使用初始账号的保留标识 |
| platform | csdn 或 xiaohongshu |
| owner_username | 已存在的本站用户名；省略时归属初始化管理员 |
| username | 已核对的平台用户名或小红书号 |
| user_id | 小红书官方稳定用户标识；CSDN 留空 |
| display_name | 显示名称 |
| profile_dir | worker 上专属会话根目录的 Linux 绝对路径 |
| worker_token_file | 仓库外私有内部凭据文件，各账号不得复用 |

本地在私有 runtime.json 设置 PLATFORM_ACCOUNTS_FILE。部署时分别设置 API_PLATFORM_ACCOUNTS_FILE 和 WORKER_PLATFORM_ACCOUNTS_FILE，两份配置身份和归属一致，路径对应各服务的私有目录。目录及文件的准备、权限和重启命令分别见两份操作手册。

移除导入配置会停止使用对应导入账号，不删除已有业务数据和会话；需要撤销凭据时使用后台解绑。用于清理导入会话的 worker 配置应保留到清理完成。

## 检查与故障处理

- 身份不匹配：停止绑定，核对所填用户名；不能通过修改账号记录换成其他人。
- 账号重复：核对当前用户已有绑定；同一真实身份不能归属另一用户。
- 需要登录：在对应账号重新验证，不使用其他账号恢复原任务。
- 浏览器占用：停止使用同一目录的其他浏览器，不手工删除活跃锁。
- 隔离工具不可用：检查 bubblewrap 和用户命名空间，Ubuntu AppArmor 环境按开发或部署文档准备项目私有执行文件；没有不隔离的降级执行模式。
- 已有外站结果未知：先核对处理记录，不能通过解绑、改账号或换请求标识重复提交。

本地业务环境已完成备份恢复与归属迁移，原 CSDN 与导入的小红书会话均通过正式执行器登录检查。当前管理员的小红书笔记只读同步及后台跨平台切换通过，列表为空；多用户链路在恢复副本使用合成身份验收，同平台多个真实账号与生产迁移仍需对应环境验收，见[验收记录](acceptance.md)。
